# 六十星系交互模型 v0.1（G4 工作稿）

## 1. 研究对象

中州派《深造讲义（上）》把十四正曜作为基础，把六十基本星系作为发展，并强调六十星系各有独特的“反应原则”。因此，本项目不把星系看作两个单星标签的拼接，而把它定义为**中尺度交互状态（mesoscopic interaction state）**。

## 2. 基本形式

单星基态：

~~~text
S_i^0
~~~

带上下文的单星状态：

~~~text
S_i(c) = T_c(S_i^0)
~~~

星系状态：

~~~text
H_s = Phi_s(S_1, ..., S_n, R_s, c)
~~~

其中：
- S_i：组成星曜的已批准气核；
- R_s：同度、对宫、三合等结构关系；
- c：四化、辅佐煞曜、庙陷、运限等条件；
- Phi_s：第 s 个星系的交互算子。

为了研究“哪些性质只是单星组合、哪些属于真正交互涌现”，再写成分析性分解：

~~~text
H_s = A_s(S) + Delta_s(S, R_s, c)
~~~

- A_s(S)：由单星气核及已知关系可以解释的部分；
- Delta_s：必须由组合、结构或条件才能解释的交互残差。

注意：这只是识别框架，不预设 Delta_s 一定非零，也不预设线性加法是正确动力学。

## 3. 为什么需要“星系模态”而不是新增60组 primitive qi

六十星系原文反复用二分或连续判别来描述“本质”，例如：

- 紫微破军：安定 / 动荡；
- 武曲天相：刚柔是否调和；
- 贪狼辰戌：坚忍 / 躁进；
- 天机太阴：理智 / 情绪；
- 紫微七杀：权威 / 横霸；
- 天机天梁：明断 / 尖刻。

这些判别很多是**已有气机变量在特定结构中的组合状态**，不宜每看到一个词就新增一个 primitive dimension。

因此引入：

~~~text
z_s = star-system mode
~~~

即“星系模态”。

完整表示：

~~~text
H_s = {base_composition, interaction_delta, mode z_s, context_gates}
~~~

## 4. 星系模态的类型

### 4.1 Balance mode — 平衡模态

两个或多个基础倾向需要达到协调区间。

例：
- 武曲天相：刚 ↔ 柔；
- 紫微天府：主动/进攻 ↔ 被动/保守；
- 天机天梁：天机的敏感变动 ↔ 天梁的原则纪律。

数学候选：

~~~text
z_s = f(q_a - q_b)
quality = - (z_s - z*)^2
~~~

这里 z* 是“中和区”，不是预设数值。

### 4.2 Mode switch — 模态转换

条件改变后，星系会进入不同性质簇，而非仅“强一点/弱一点”。

例：
- 紫微破军：安定 ↔ 动荡；
- 巨门子午：英华内敛 ↔ 内心疑忌；
- 天府巳亥：祥和 ↔ 权术。

候选形式：

~~~text
z_s ∈ {mode_A, mode_B, ...}
P(z_s | S, c)
~~~

Paper 1 只建立符号条件，不估计概率。

### 4.3 Gated mode — 条件门控模态

特定四化、辅佐、煞曜或宫位结构决定某种机制是否被激活。

例：
- 紫杀本有权力性，但权力过强且无辅佐调和时可转横霸；
- 天相本身柔和，但刑忌夹、财荫夹可使同一基础性质出现相反发展。

候选形式：

~~~text
z_s = G(c) · f(S)
~~~

其中 G(c) 先使用布尔/符号门控。

### 4.4 Relational mode — 关系模态

主要改变的是系统与外界/他人的关系，而非单纯内部心理状态。

例：
- 太阳巨门：得助 ↔ 孤立；
- 太阳辰戌：受拖累 ↔ 不受拖累；
- 紫微天相：有情 ↔ 无情。

这些首先进入 L2 关系网络层。

## 5. 星系交互证据分类

每条星系规则标记：

### COMPOSITION
可由已批准单星气核和关系直接解释。

### INTERACTION
只有组合后才出现、或组合改变原变量含义。

### MODE_SWITCH
同一星系因条件进入不同稳定性质簇。

### CONTEXT_GATE
四化、辅佐煞曜、夹宫、庙陷等决定交互是否激活。

### PROJECTION
只是该模态在某宫位/人生领域的下游表现，不进入星系 primitive state。

## 6. 交互残差 Delta_s 的认识论含义

Delta_s 不代表神秘“新能量”，只表示：

> 当前单星气核 + 已有结构变量不足以重构源文中该星系性质时，需要保留一个未解释交互项。

后续有三种可能：

1. **可约化**：扩充/修正基础气机后，Delta 逐渐消失；
2. **稳定涌现项**：多个规则反复要求同一组合特性；
3. **文本特例**：只存在于少量传统经验规则，不能泛化。

系统辨识之前不人为给 Delta_s 连续数值。

## 7. 星系不是独立60个模型

六十星系实际上共享大量“反应模态”，例如：
- 稳定/动荡；
- 积极/消极；
- 理智/情绪；
- 权威/横霸；
- 有目标/盲动；
- 坚忍/躁进。

因此 G4 的目标不是训练 60 个完全独立模型，而是寻找：

~~~text
60个星系
↓
若干可复用交互模态族
↓
共同的气机动力学
~~~

这可以显著降低后续参数维数，并提高系统辨识的可辨识性。

## 8. 与控制理论的接口

若把 z_s 视为离散/连续模态变量，则本系统更接近**混杂动力系统（hybrid dynamical system）**：

~~~text
x_(t+1) = F_{z_t}(x_t, u_t, G_t; theta)
z_(t+1) = M(z_t, x_t, u_t, G_t)
~~~

其中：
- x_t：连续/序数气机状态；
- z_t：星系模态；
- u_t：运限等外生输入；
- G_t：星系、宫位、三方四正等关系结构。

Paper 1 只定义结构，不进行数值辨识。

## 9. G4 后进入下一阶段的条件

只有当以下内容完成后，才进入辅佐煞化/宫位投影与完整状态方程：

1. 六十星系索引完成；
2. 每个星系至少有一个 principal mode；
3. interaction evidence 可追溯；
4. primitive qi 与 system mode 分离；
5. 重复模态完成聚类；
6. 红队确认没有把下游事件重新塞回潜状态。
