# Formal Definitions

Version: 0.1

## D1. Latent qi state

A latent qi state is a model-internal variable introduced to represent recurring directional, relational, or dynamical properties extracted from the approved Zhongzhou corpus.

It is not assumed to be a directly measurable physical substance.

## D2. Star core

A star core is the source-constrained latent-state signature associated with one major star before contextual interaction.

## D3. Star-system core

A star-system core is the state produced by the interaction of one or more star cores under a specified structural context.

It is not assumed to be the arithmetic sum of component-star cores.

## D4. Modifier operator

A modifier operator acts on a star/star-system state by strengthening, weakening, transforming, inhibiting, activating, or conditionally changing one or more latent-state components.

## D5. Palace projection

A palace projection maps a latent state to a domain-specific semantic/observable space.

A palace is therefore treated as a contextual projection field, not merely as an event label.

## D6. Natal essence

The natal essence is the baseline structured state derived from the natal configuration before temporal-layer stimulation.

## D7. Temporal stimulus

A temporal stimulus is an exogenous, non-controllable model input associated with decade/year/month-level configurations.

## D8. Response

A response is the state-dependent change produced when a temporal stimulus acts on an existing natal/current state.

## D9. Observation

An observation is a measurable or annotatable manifestation in a domain-specific output space.

Paper 1 formalizes the observation interface but does not claim externally validated probabilities.

## D10. Provenance

Provenance is the trace from a formal statement back to approved source text and intermediate transformations.
