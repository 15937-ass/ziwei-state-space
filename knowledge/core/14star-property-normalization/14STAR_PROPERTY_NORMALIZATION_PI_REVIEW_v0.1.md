## 目前观察

太阳试点与太阴当前试点显示，至少需要分开记录以下层次：

1. 原文直接描述的基础倾向；
2. 入庙、过强、光热不足等条件下的补偿或状态变化；
3. 对其他星曜会合的关系依赖；
4. 声名、贵显、财富、六亲与传统健康应象等下游结果；
5. 运限机会和巳午宫位比较等有时间/比较范围的主张；
6. 一般推断方法与单星自身性质之间的边界。

太阳的发射倾向与太阴的潜藏/收敛倾向均与既有 QI-01 的相反方向存在可解释对应，均仅为 `supported_candidate`，不是 canonical 接受，`normalization_epistemic` 继续为 `UNRESOLVED`。太阴来源还显示 QI-01 必须保留最优区域，不能把收敛单调化。

## 三颗试点横向比较：方法结论

### 共同结论
- **L0 与 L1 分离：** 阴阳五行等结构底座不直接当作 QI 数值。太阳“向外发射”与太阴“潜藏/收敛”支持 QI-01 的相反方向性候选，但都保持 normalization_epistemic=UNRESOLVED；太阴的“适度收敛”阻止单调化。天相的已审跨度更支持上下文依赖和关系门控，不直接支持固定 QI-02 柔和/软弱基线。
- **条件与关系必须保真：** 太阳的过度发射联合门控、太阴的过度收敛 OR 分支与太阳补偿、天相夹宫/具体四化主体/化解条件，均不能被压成无条件星性。
- **L2/L3 不得混层：** 三星的跨星、跨宫、夹局、星系组合和传统结果分别保留。声名、财富、六亲、传统健康、离乡、守成与技艺谋生等不是由本轮材料验证的现实结果。
- **重复来源不重复计证：** 同句被多个规则引用时保留各规则的条件/目标差异，但独立来源跨度只计一次。
- **来源与归一化认知状态分开：** 视觉核对短跨度不自动证明目标映射正确；p46“是非尤的徵兆”与 canonical target“是非怨尤”的字面差异保持未决。

### 对研究方法的判断
当前没有发现必须修改共享 schema 才能记录三星试点的阻塞。建议下一阶段继续使用已接受的 #755 v0.1 逐目标审核契约、来源主张卡与缺口清单；机器校验只验证结构和值域，不能代替人工语义审查。该判断不意味着任何单星映射已被接受。
