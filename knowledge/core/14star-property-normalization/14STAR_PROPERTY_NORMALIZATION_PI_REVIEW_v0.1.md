# 十四主星基础性质归一化：PI 审议材料 v0.1

**状态：** `IN_PROGRESS_NOT_READY_FOR_PI_DECISION`  
**Issue：** #757  
**范围：** 太阳试点检查点；不是最终十四星审议包。

## 目前观察

太阳试点显示，至少需要分开记录以下层次：

1. 原文直接描述的基础倾向；
2. 入庙、过强、光热不足等条件下的补偿或状态变化；
3. 对其他星曜会合的关系依赖；
4. 声名、贵显、财富、六亲与传统健康应象等下游结果；
5. 运限机会和巳午宫位比较等有时间/比较范围的主张；
6. 一般推断方法与单星自身性质之间的边界。

当前最有依据的基础候选是太阳的发射倾向与既有 QI-01 方向的对应；这仍是 `supported_candidate`，不是 canonical 接受，`normalization_epistemic` 继续为 `UNRESOLVED`。

## 本轮明确不请求的决定

- 不请求现在批准 QI-01 的正式映射。
- 不请求修改 QI-05、QI-15 或 L3 输出语义。
- 不请求修改 `star_cores.yaml`、`qi_ontology.yaml` 或任何 canonical 规则。
- 不请求 Product 消费候选材料。

## 尚待完整研究后再提交的审议问题

- 对每颗星，哪些原文只支持描述、哪些足以支持某个候选目标？
- 如何保留比较对象、条件、例外、时间范围和原文替代项？
- 对同一原文跨度对应不同规则/目标时，如何保持可追溯且不重复计证？
- 哪些项应保留为 UNKNOWN、MISSING、CONFLICT 或 NOT_APPLICABLE，而不是强行填满十四星同质向量？
- 哪些归一化选择需要 PI 语义裁决，哪些仅是机械审核？

待太阳、太阴、天相三个试点完成并检查方法后，再扩展剩余十一星。最终材料会将有支持的候选、未决项、反例与不能推出的结论分开呈现。
