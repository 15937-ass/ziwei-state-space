## 目前观察

太阳试点与太阴当前试点显示，至少需要分开记录以下层次：

1. 原文直接描述的基础倾向；
2. 入庙、过强、光热不足等条件下的补偿或状态变化；
3. 对其他星曜会合的关系依赖；
4. 声名、贵显、财富、六亲与传统健康应象等下游结果；
5. 运限机会和巳午宫位比较等有时间/比较范围的主张；
6. 一般推断方法与单星自身性质之间的边界。

太阳的发射倾向与太阴的潜藏/收敛倾向均与既有 QI-01 的相反方向存在可解释对应，均仅为 `supported_candidate`，不是 canonical 接受，`normalization_epistemic` 继续为 `UNRESOLVED`。太阴来源还显示 QI-01 必须保留最优区域，不能把收敛单调化。
