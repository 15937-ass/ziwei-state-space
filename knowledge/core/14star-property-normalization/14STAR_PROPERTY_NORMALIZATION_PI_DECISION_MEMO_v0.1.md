## 2. 为什么需要这项研究？

当前仓库已经有十四主星规则、QI/QR 本体和星核结构，但“古籍中有一条关于某星的描述”与“这条描述可以作为某个现代性质维度的直接证据”并不是一回事。

例如，原文可能同时谈到：
- 一颗星的基础倾向；
- 这颗星在特定状态下的变化；
- 其他星曜、夹宫或对宫对它的影响；
- 财富、声名、六亲、健康等传统下游应象；
- 运限、宫位比较或一般论命方法。

如果把这些全部压成同一组“星性形容词”或数值向量，就可能把结果当成原因、把外部条件当成星曜自身性质、把有条件的规则改写成无条件结论。因此，本研究首先检验：能否在不丢失原文条件与证据边界的前提下，逐步整理候选性质。

## 3. 三个试点为什么有比较价值？

三个试点不是为了证明十四星必然符合某一套向量，而是展示不同类型的证据会给方法带来什么挑战。

### 3.1 太阳：基础方向、强弱条件与结果必须分开

- **来源直接描述：** 太阳的核心倾向被描述为向外发射光和热。
- **候选对应：** 可与现有 QI-01「发射—收敛」的发射端建立可解释的候选对应。
- **条件变化：** 太阳入庙且同时会合过多发射性质星曜时，来源提出过度发射风险；“入庙”和“会合过多发射星曜”两个条件都不能丢。
- **补偿规则：** 太阳过强与光热不足时，来源分别提出不同的调节方向。这是条件反应，不代表太阳始终需要某一种补偿。
- **下游结果：** 声名、贵显与财富不等同于“发射性”；财富还依赖其他财富性质星曜会合。
- **方法提醒：** 一般中和原则不能单独证明太阳本身拥有 QI-15「缓冲/调和能力」。

太阳的作用是测试：能否保留基础方向，同时不把条件、补偿、关系和结果全部塞进一个基础性质。

### 3.2 太阴：相反方向也不等于越多越好

- **来源直接描述：** 太阴的核心倾向被描述为潜藏与收敛。
- **候选对应：** 可与 QI-01 的收敛端形成方向性候选。
- **最优区域：** 来源还强调适度收敛等条件。因此不能把轴理解成“越收敛越好”，也不能擅自添加数值强度。
- **条件分支：** 过度收敛的来源条件包含替代分支，必须保留 OR，不能静默改成所有条件同时成立的 AND。
- **跨星补偿：** 太阳在特定状态、化禄和三方四正会合等条件下才参与补偿。这是关系/条件，不是太阴自身无条件具有发射性。
- **其他分支：** 昌曲成对或单见、有禄或无禄，以及星系稳重/浮动，需要分别记录。
- **下游结果：** 财富、六亲、传统健康应象不能自动当成太阴的基础内在性质。

太阴的作用是测试：能否保留最优区域、OR/AND、跨星关系和非单调条件，而不是强行把一颗星写成单一方向的绝对量。

### 3.3 天相：不能因为来源谈到某星，就一定要给它一个固定内在向量值

- **来源重点：** 当前已审跨度更强调天相受环境影响、夹宫优先和关系条件。
- **QI-02 问题：** 现有 QI-02 是「刚—柔」轴，并非“强弱”轴。当前已审来源不足以直接证明天相固定处在柔和端，或天相本身有固定的软弱倾向。
- **象征与能力：** 印绶/掌印官可以是象征性权威，不等于天相自身具有现实权力、领导力或自主能力。
- **关系条件：** 财荫夹、刑忌夹、对宫破军、具体四化主体和化解条件，需要保留其关系和门控结构，不能一律归入天相单星的内在性质。
- **未决字面：** 印刷页 46 的扫描可见“是非尤的徵兆”，而 canonical target 写作“是非怨尤”。本轮不擅自补字或改写正式规则。

天相的作用是测试：方法能否接受“现有来源更支持上下文/关系候选，而不是固定内在性质”这一结果，而不为了填满向量强行给它一个值。

## 4. 本轮采用的分层方法是什么意思？

这里的分层是为了区分证据在说什么，并不是要求 PI 现在批准每个维度。

| 层次 | 通俗含义 | 本轮例子 | 不能做的事 |
|---|---|---|---|
| L0 结构底座 | 阴阳、五行等背景标签 | 太阳、太阴、天相各自的结构标签 | 不能直接当作 QI 数值或强弱分数 |
| L1 内在气机状态 | 原文直接支持的基础倾向候选 | 太阳发射、太阴收敛 | 不能把候选当成已批准映射 |
| L2 关系与网络状态 | 性质如何受其他星、夹宫、对宫、星系或跨宫关系影响 | 太阴受太阳条件补偿；天相受夹宫关系影响 | 不能把外部关系直接记成单星恒定性质 |
| L3 场景投影 | 传统文本描述的财富、名誉、地位、六亲、健康等结果 | 太阳声名/财富；太阴财富/六亲 | 不能把结果倒推成内在性质，也不能据此宣称现实预测有效 |
| L4 评价层 | 在特定条件下如何评价吉凶、适配、风险或中和 | 某种组合在某条件下被描述为有利或不利 | 不能把条件性评价当成基础性质本身 |

### 几个关键 QI 术语

- **QI-01「发射—收敛」：** 描述向外显发与向内潜藏/收束的动力学方向，并允许存在最优区域。发射不等于吉，收敛也不等于凶。
- **QI-02「刚—柔」：** 描述作用方式偏强硬/压制，还是偏调和/缓冲/顺应；它不是“能力强弱”的同义词。
- **QI-05「现实化—空泛」：** 描述意图或计划能否落到具体、现实、可执行层面。某段文字出现“虚浮”不自动证明它应映射到 QI-05，仍需核对条件与目标定义。
- **QI-15「缓冲/调和能力」：** 描述吸收冲突、降低极端或趋向平衡的能力。一般论命方法要求“中和”，不等于某颗星本身具有这项内在能力。

这些 QI 名称是仓库已有模型中的候选语义工具。本轮不要求 PI 新增维度、修改维度定义或决定任何正式映射。

## 5. 现有审核契约够不够？本轮到底验证了什么？

本轮复用了 #755 / PR #758 已合入的 Mapping Review Schema v0.1。每条逐目标审核记录需要明确：
- 来源引用；
- 一个具体目标；
- 为什么考虑该目标；
- 证据角色（例如基础状态、状态变化、外部修正、互动或下游结果）；
- 当前处理意见（例如候选、需要复审、支持候选、不支持该目标等）。

这套契约允许明确记录 UNKNOWN、MISSING、CONFLICT 或 NOT_APPLICABLE 等状态，而不是为了填满表格而猜一个答案。

**本轮结论：** 对三颗试点的记录形状而言，现有契约够用，没有发现必须扩展共享 schema 的阻塞。

但必须区分两种验证：
1. **机器验证：** 检查字段、值域、引用和仓库治理约束是否符合规则。
2. **语义审查：** 人工判断原文解释是否准确、条件有没有丢失、映射是否真的成立。

测试通过只能证明机器可检查的部分通过，不能证明古籍解释或 QI 映射在语义上正确。因此，后续仍需逐星阅读性质卡、逐目标理由与来源跨度。
