## 1. 结论先行

这轮没有证据支持“八组都应该合并”，也没有证据支持“八组都已证明互相独立”。初步结论是：

- **明显的层级/角色混用候选**：QI-02/QI-15、QR-01/QR-04。
- **共享来源规则、但概念仍可区分**：QI-03/QI-04。
- **定义可区分、当前缺少同规则重叠证据**：QI-01/QI-14、QI-08/QI-06、QI-04/QI-16、QI-08/QI-16。
- **来源明确支持概念分开，但仍是候选维度**：QI-17-CAND/QI-18-CAND。

以上均是研究处置，不是正式 ontology 状态；不合并、不删除、不改名、不接受任何映射。

## 2. 方法和证据边界

输入为当前 `knowledge/qi_ontology.yaml`、`star_cores.yaml`、十四主星矩阵及两批已合并的 DIRECT_STAR 来源优先审查。对源文明确出现的例子，优先使用来源规则 ID 和页码；原矩阵中的 `evidence_text` 只是摘要，不能替代逐字引文。十四主星来源审查的 `VERIFIED_VISUAL_SCAN` 仅适用于相应已核对的原扫描页。

- 来源认识论状态与归一化认识论状态分开；所有现有归一化仍为 `UNRESOLVED`。
- 共享 rule ID 不等于两个维度等价；一个规则同时被两个维度引用，也不构成两份独立证据。
- 没有共同规则引用也不等于两维度已证明正交；仍需反例与可区分的来源例子。
- `QI-17-CAND` 与 `QI-18-CAND` 保持候选身份；本轮不授予正式原语或映射地位。
- 本轮不推导数值权重、概率、阈值、正交分数或现实预测有效性。

## 3. 八组逐对结论

### OVERLAP-01 — QI-01 / QI-14

**当前定义**

- QI-01（发射—收敛）：气机向外扩散、显发与向内潜藏、收束之间的动力学倾向。
- QI-14（信息/状态遮蔽—显露）：信息、意图、能力或状态被隐藏、遮蔽，或被显露、可辨识的程度。

**证据与观察**：太阴来源把潜藏/收敛描述为动力学倾向；巨门来源以暗曜及太阳化解暗蔽描述信息/状态的可见性。现有本体 modeling note 也明确说 QI-01 不等同信息可见性。

- 相关规则：`ZZ-TYI-002`、`ZZ-JM-002`、`ZZ-JM-X04`、`ZZ-JM-X10`。
- 来源定位：SRC-ZZ-002 printed p19；SRC-ZZ-002 printed pp23–24；SRC-ZZ-001 printed p83。
- 当前引用关系：NO_SHARED_RULE_ID_FOUND_IN_CURRENT_MATRIX。

**区分假设**：两者可相关但不等价：一个描述气机方向/收束程度，另一个描述信息或状态是否可被看见/辨识。

**反例/限制**：“潜藏”在一般语言中可同时指向内收与不显露，但来源没有证明二者总是同步。不能因词面相似就合并，也不能仅凭定义宣布完全正交。

**研究处置**：`OVERLAP_BUT_DISTINCT_CANDIDATE`。

**未决问题**：需要更多同一来源中将收敛与遮蔽明确区分或联动的成对例子；当前没有同一规则同时指向 QI-01 与 QI-14。

### OVERLAP-02 — QI-03 / QI-04

**当前定义**

- QI-03（稳定—变动）：系统保持既有结构与发生迁移、转换、重组之间的倾向。
- QI-04（守成—开创/冲刺）：维护既有结构、资源与秩序，或主动突破既有结构推动新局的倾向。

**证据与观察**：破军“冲锋/不主退守”的同一规则同时被引用到 QI-03 与 QI-04；“旧事创新”则描述变化与既有事项的联系。天府守成与开创的比较提供另一方向的对照。

- 相关规则：`ZZ-PJ-002`、`ZZ-PJ-003`、`ZZ-PJ-X10`、`ZZ-TF-005`。
- 来源定位：SRC-ZZ-002 printed pp31–32；十四正曜·天府·书页17。
- 当前引用关系：SAME_RULES_REFERENCED_BY_BOTH_QI_03_AND_QI_04。

**区分假设**：QI-03 应回答“结构是否发生变化”；QI-04 应回答“变化相对守成的方向/方式是否偏开创或冲刺”。变化不自动意味着开创新局。

**反例/限制**：破军“冲锋”文本可同时被读作变化和开创，因此当前共享引用确有歧义。相同句子被两个维度引用不构成两个独立证据，也不证明维度等价。

**研究处置**：`OVERLAP_BUT_DISTINCT_CANDIDATE`。

**未决问题**：需要一组明确“发生变化但不具开创方向”以及“维持结构但主动开创”的来源案例，以检验边界。

### OVERLAP-03 — QI-02 / QI-15

**当前定义**

- QI-02（刚—柔）：作用方式偏强硬、切断、压制或偏调和、缓冲、顺应的程度。
- QI-15（缓冲/调和能力）：吸收冲突、降低极端、化解不利或使不同性质趋向平衡的能力。

**证据与观察**：武曲的刚烈/刚克可在天府、禄存或化禄等条件下被收敛/调和；现有矩阵将相关规则同时链接到 QI-02 与 QI-15。天同“和气/善化凶”也曾被分别关联到刚柔与缓冲。

- 相关规则：`ZZ-WQ-020`、`ZZ-WQ-022`、`ZZ-TT-002`、`ZZ-TT-006`。
- 来源定位：SRC-ZZ-002 printed p11；SRC-ZZ-002 printed pp13–14；SRC-ZZ-001 诸星曜基本性质·天同。
- 当前引用关系：SAME_RULES_ZZ_WQ_020_AND_ZZ_WQ_022_LINK_TO_BOTH; ZZ-TT-002 HAS MULTI-TARGET CANDIDATE LINKS。

**区分假设**：QI-02 描述状态/作用方式落在刚柔轴的哪一侧；QI-15 描述调节、吸收冲突或化解极端的功能能力。一个调节过程可能改变刚柔状态，但状态变化不自动证明主体具备独立的缓冲能力。

**反例/限制**：同一条“刚烈被收敛”证据可描述 QI-02 的状态变化，也可被解释为 QI-15 的调节作用；但来源中的调节者可能是天府/禄存等外部条件，而不是武曲的内在能力。

**研究处置**：`LAYER_OR_ROLE_MISMATCH_CANDIDATE`。

**未决问题**：需明确 QI-15 是主体可复用能力、外部 modifier 的功能，还是系统交互结果；未定义前不应接受双重映射。

### OVERLAP-04 — QI-08 / QI-06

**当前定义**

- QI-08（行动驱动）：把内部意图转换为主动行动、执行、进取和实际推进的驱动力。
- QI-06（决策激活度）：从决策延迟到适度审慎，再到过度冲决的激活程度。

**证据与观察**：武曲昌曲条件可出现优柔寡断，武曲见破军可转为躁决；七杀的独行与破军守命后的持续承担任务，则是行动/执行方面的描述。

- 相关规则：`ZZ-WQ-019`、`ZZ-WQ-024`、`ZZ-QS-004`、`ZZ-PJ-X02`。
- 来源定位：SRC-ZZ-002 printed pp11–12；SRC-ZZ-002 printed p29；SRC-ZZ-002 printed pp31–32。
- 当前引用关系：NO_SHARED_RULE_ID_FOUND_IN_CURRENT_MATRIX。

**区分假设**：QI-06 描述决策过程的激活区间，允许低端迟疑与高端躁决；QI-08 描述将意图转为行动的驱动力。二者可能相关，但“决得快”不等于“能持续执行”，“行动多”也不等于决策恰当。

**反例/限制**：当前矩阵未发现同一规则同时指向 QI-08 与 QI-06；现阶段是概念边界审查，不是已证实的重复映射。源文中的“躁决/优柔”也不能直接推成行动能力高低。

**研究处置**：`DISTINCT_CONSTRUCTS_CANDIDATE`。

**未决问题**：需要同一配置下分别记录决策迟疑/躁决与实际行动启动/执行的来源案例，检验是否有必要保留两个轴。

### OVERLAP-05 — QI-04 / QI-16

**当前定义**

- QI-04（守成—开创/冲刺）：维护既有结构、资源与秩序，或主动突破既有结构推动新局的倾向。
- QI-16（目标导向性）：行动、变化与资源投入具有明确目标、方向与建设性组织的程度。

**证据与观察**：破军的冲锋/开创描述与 QI-16 对有目的建设、无目的破坏的区分相关，但并非同一概念。当前本体说明变化多、行动强、开创强均不充分推出目标明确。

- 相关规则：`ZZ-PJ-002`、`ZZ-PJ-X06`、`ZZ-SYS-09-004`、`ZZ-SYS-09-006`、`ZZ-SYS-31-003`、`ZZ-SYS-31-004`、`ZZ-SYS-52-038`。
- 来源定位：SRC-ZZ-002 printed pp31–32；六十星系相关规则（需按各规则定位复核）。
- 当前引用关系：NO_SHARED_RULE_ID_FOUND_FOR_QI_04_AND_QI_16_IN_CURRENT_MATRIX。

**区分假设**：QI-04 描述维护/突破的方向；QI-16 描述行动或变化是否受明确目标组织。可以高开创而目标不清，也可以有明确目标但选择守成。

**反例/限制**：ZZ-PJ-X06 的 canonical 条件比已核验源文更具体；来源此处的“或”不能被改成更强合取。该规则目前不能单独作为 QI-16 已被充分证明的依据。

**研究处置**：`DISTINCT_CONSTRUCTS_BUT_EVIDENCE_MIXED`。

**未决问题**：需对引用的六十星系例子逐条做原文页核验，并修复/解释 ZZ-PJ-X06 的条件范围差异后，才能评价目标导向维度的证据充足性。

### OVERLAP-06 — QI-08 / QI-16

**当前定义**

- QI-08（行动驱动）：把内部意图转换为主动行动、执行、进取和实际推进的驱动力。
- QI-16（目标导向性）：行动、变化与资源投入具有明确目标、方向与建设性组织的程度。

**证据与观察**：行动/任务承担的来源描述不等于目标明确；破军的条件性“破坏而欠建设”候选被用于目标质量维度，但其条件归一化仍有未决差异。

- 相关规则：`ZZ-PJ-X02`、`ZZ-PJ-X06`、`ZZ-QS-004`、`ZZ-TL-008`。
- 来源定位：SRC-ZZ-002 printed pp29–32；SRC-ZZ-001 printed p83。
- 当前引用关系：NO_SHARED_RULE_ID_FOUND_FOR_QI_08_AND_QI_16_IN_CURRENT_MATRIX。

**区分假设**：QI-08 描述行动启动/推进驱动力；QI-16 描述行动的目标组织性。高行动驱动可用于建设，也可用于无目的或破坏性行动。

**反例/限制**：当前直接来源中，破军守命承担困难任务可支持行动/任务驱动，却不能单凭该句推断目标明确；ZZ-PJ-X06 的源文条件差异进一步限制了强结论。

**研究处置**：`DISTINCT_CONSTRUCTS_CANDIDATE`。

**未决问题**：需用相同动作强度、不同目标质量的对照源文，检验 QI-08 与 QI-16 是否能独立变化。

### OVERLAP-07 — QI-17-CAND / QI-18-CAND

**当前定义**

- QI-17-CAND（意志控制强度（候选））：在欲望、情绪、诱因或环境压力下维持自主约束与方向的能力。
- QI-18-CAND（毅力/持续性（候选））：在时间、阻力、延迟或重复挫折下维持行动的持续程度。

**证据与观察**：天同巳亥的原文分别讨论意志强弱与毅力不足，并明确指出两者不同；意志薄弱者也可能有毅力。该来源提供了当前最直接的区分证据。

- 相关规则：`ZZ-SYS-48-002`、`ZZ-SYS-48-007`、`ZZ-SYS-48-009`、`ZZ-SYS-48-012`、`ZZ-SYS-38-009`、`ZZ-SYS-22-002`、`ZZ-SYS-22-003`、`ZZ-SYS-22-004`、`ZZ-SYS-22-005`。
- 来源定位：SRC-ZZ-002 printed pp133–135；SRC-ZZ-002 printed pp77–78；SRC-ZZ-002 printed pp110–112。
- 当前引用关系：CANDIDATE_DIMENSIONS; SOURCE EXPLICITLY DISTINGUISHES WILL FROM PERSEVERANCE。

**区分假设**：意志控制关注面对诱因/压力时的约束与方向；毅力关注时间与阻力下是否持续。前者较强不必然保证后者强，反之亦然。

**反例/限制**：这支持把两个候选概念分开研究，但不自动证明它们应成为正式 QI 原语，也不授权接受 QI-17-CAND/QI-18-CAND 的映射或定义。

**研究处置**：`SOURCE_SUPPORTS_DISTINCT_CANDIDATES_ONLY`。

**未决问题**：候选维度是否具有跨星曜复用性、与 QI-03/QI-06/QI-08 的边界如何定义，仍需更多独立例子和 PI/Human Gate。

### OVERLAP-08 — QR-01 / QR-04

**当前定义**

- QR-01（关系整合—孤离）：关系网络中的嵌入、支持、协同程度与孤立、疏离、孤克程度。
- QR-04（支持资源）：来自辅佐、同伴、属下、组织或贵人网络的可用支持程度。

**证据与观察**：紫微在左辅右弼三方会合时，源文分别描述助力与属下众多；现有矩阵将两条投影证据同时关联 QR-01 与 QR-04。它们描述资源/结果，不足以单独证明关系整合程度。

- 相关规则：`ZZ-ZW-013`、`ZZ-ZW-014`、`ZZ-TLIA-004`、`ZZ-TLIA-X05`、`ZZ-WQ-006`、`ZZ-WQ-010`、`ZZ-WQ-021`。
- 来源定位：SRC-ZZ-002 printed p5；SRC-ZZ-002 printed pp27–28；十四正曜·武曲·书页11。
- 当前引用关系：ZZ-ZW-013_AND_ZZ-ZW-014_LINK_TO_BOTH_AS_PROJECTION_EVIDENCE。

**区分假设**：QR-01 描述关系网络的整合或孤离状态；QR-04 描述可获得的支持资源。资源数量、可用性、互惠程度与实际关系嵌入不是同一变量。

**反例/限制**：属下众多或外部助力多，不必然意味着亲密、互惠或低孤离；反之，关系网络整合也不保证在特定任务中有可用资源。两条现有证据均属 projection tier。

**研究处置**：`LAYER_OR_ROLE_MISMATCH_CANDIDATE`。

**未决问题**：需区分关系网络状态、资源可用性与下游助力结果；当前投影证据不应直接接受为两个 QR 维度的等权直接证据。


## 4. 横向发现

1. **状态与调节功能不能混层**：QI-02 描述刚柔状态，QI-15 描述缓冲/调和功能；条件性“某星曜使另一星刚烈减弱”首先是交互/修饰证据，不自动证明被修饰星自身具有缓冲能力。
2. **变动、开创、行动和目标是不同问题**：变动问结构是否改变；开创问是否突破旧结构；行动驱动问能否推进；目标导向问行动是否受明确方向组织。一个源文规则可以同时触及多项，但需要独立证据或可复核的复合映射理由。
3. **关系整合不等于资源数量**：QR-01 是关系网络整合/孤离；QR-04 是支持资源。紫微“助力/属下众多”的现有链接是投影证据，不能据此把两个 QR 维度视为等价。
4. **意志与毅力有明确的来源区分**：六十星系·48 的原文明确区分意志强弱与毅力，且指出意志薄弱者也可能有毅力。这支持候选概念分开研究，但不自动授权把候选维度正式化。
5. **条件差异不能当作冲突或独立性的充分证明**：例如 `ZZ-PJ-X06` 的 canonical 条件比已核验源文更具体，仍需处理条件范围差异；本轮不修订该规则。
6. **无共同引用不是“正交证明”**：QI-01/QI-14、QI-08/QI-06、QI-04/QI-16、QI-08/QI-16 当前未发现同一规则同时链接两侧，但仍需针对性反例和独立来源支持。
