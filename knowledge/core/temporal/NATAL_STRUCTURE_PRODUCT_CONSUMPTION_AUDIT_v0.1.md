## 一、这轮研究的目的

不是重建已经通过 G5 / A2-R1 的 v0.5 架构，也不是替 Product 实现时间层引擎。本轮先把三件事分开：

1. 已经由 Core 冻结的本质结构；
2. Product 当前能够接收、展示和校验的证据接口；
3. 原书已经支持、但尚未形成通用语义规则的时间层关系。

结论必须分成来源明示、项目形式化、Product 契约、未决，不把架构命名误当成古籍原文。

## 二、NATAL 本质结构：应复用什么

### 2.1 v0.5 已经冻结的核心

接受的 v0.5 模型不是“一个总分再输出十二宫”，而是：

- 每个宫位有自己的原局本质 (e_p)；
- 十二个 (e_p) 组成原局本质集合 (E)；
- 宫位之间通过有来源依据的稀疏全局图 (G_0) 联动；
- 大限、流年等作为外生时序输入，不重写固定原局本质；
- 当期反应 (r_{p,t}) 依赖原局本质、时序输入、星系模态、跨宫邻域与现实上下文；
- 最后才经宫位投影形成语义输出。

所以 v2.2 计划中的 `N`，可以作为对 v0.5 固定原局本质 `E={e_p}` 的项目级命名对照。**这不是新增本体，也不需要再造一套 NATAL 图。**

### 2.2 必须保持分离的对象

| 计划对象 | v0.5 对照 | 审计结论 |
|---|---|---|
| `N` | 固定 `E={e_p}` | 可复用，命名对照 |
| `E_decade` | `u_(p,t)` / `U_p` 的大限层输入 | 可复用输入接口，但关系规则仍需来源研究 |
| `E_year` | `u_(p,t)` / `U_p` 的流年层输入 | 可复用输入接口，但不得与大限自动相加 |
| `tau_t` | `r_(p,t)` / `R_theta` | 对应反应层，不是环境本身 |
| `M0` | 与 `y_p`、`Y_semantic`、`Y_observed` 有关 | 暂无一对一映射；应保留为候选表现层 |
| `M_t={D_t,H_t}` | A2-R1 typed history memory | 已有批准结构，必须保持独立 |

尤其注意：**大限/流年环境 ≠ 触发条件 ≠ 反应结果 ≠ 现实事件。**

## 三、Product 当前消费契约：能复用什么

### 3.1 QuickRead / DetailedRead 已有的能力

- QuickRead 以明确的 domain + time-layer slot 组织请求；slot 是请求/覆盖单位，不是完整的原局状态图。
- 证据分为 RUNTIME、SOURCE、MODEL_SUPPLEMENT 三条通道；模型补充不会增加项目的 Runtime 或 Source 覆盖。
- NATAL 证据不能被重新标记成 YEAR 或 DECADE。
- 非 NATAL 的响应/表现 slot 必须有 TEMPORAL 证据；时间层必须精确匹配请求。
- DetailedRead 已经要求十二个 NATAL domain slot，并把 DECADE / YEAR temporal slots 分开；其主题式分阶段输出是展示编排，不会自动产生时间层语义。

因此，Product 已有的请求接口和证据分层可以直接复用，不应在 Core 重建。

### 3.2 Product 当前不能做什么

PL3-T 只允许在以下条件同时成立时匹配 reaction：

1. 原始来源页已经核验；
2. 归一化明确且非假设；
3. 不是 CASE_SUPPORT_ONLY；
4. 有明确 NATAL antecedent；
5. 有明确正向 temporal condition；
6. 所有 temporal atoms 都绑定到选定的 reaction layer。

它不会从自由文本、关键词或“TIMING_TRIGGER”标签自动推导执行条件。当前生产 temporal reaction registry 仍为空。

已接受的 WP07B handoff 记录：**44 条候选、0 条符合当前编译契约**。这不是放宽契约的理由，而是说明来源条件与结构化映射仍有缺口。

### 3.3 所有权判断

- “NATAL 本质图尚未完整实现”属于 Product 实现/验证问题，不应倒逼 Core 修改 v0.5。
- “当前适配器只消费一个时间层快照”属于 Product 接口能力边界，不等于来源已经支持通用多年度执行。
- Core 只负责共享语义和来源约束；不改 Product 代码、KIB、锁或 Runtime。

## 四、NATAL / DECADE / YEAR 关系矩阵

| 关系 | 当前可确认的内容 | 当前状态 |
|---|---|---|
| NATAL → DECADE | 固定原局本质是大限反应的对象 | 来源/模型层面有描述支持 |
| NATAL → YEAR | 固定原局本质也是流年反应的对象 | 来源/模型层面有描述支持 |
| DECADE → YEAR | 两个时间层意义不同，原文有时同时提及 | 组合关系未决 |
| 时间环境 → 触发条件 | 环境提供当期事实，规则还需要明确条件 | 不能自动推导 |
| 触发条件 → `tau_t` | Product 要求 NATAL antecedent + 同层正向条件 | 契约要求，不等于所有古籍条件已满足 |
| `tau_t` → `M0` | 反应可以进入表现候选层 | 尚无一对一映射 |
| 历史记忆 | 只有来源明示跨期改变时才更新 | D/H 分型已批准 |
| 事件相对时间 | 迁移后三年窗口有独立批准 | 仅限该事件，不是通用计时器 |

**当前最重要的 HOLD：不能默认把大限与流年相加、合取、互相继承，或设定固定优先级。**

WP03 的来源审查总结确实指出：同一星系在大限与流年的意义可能不同，流年可表现为短期触发，大限可形成较长期路径；但这并没有建立一个适用于所有规则的 DECADE→YEAR 组合算子。

## 五、必须保留的来源反例

### 5.1 CA09-851：多年连续流年

来源：SRC-ZZ-003，事业宫印刷 p154 / PDF 物理 p77。

审查已将其定为“多年连续年度窗口”：

- “连续”是序列要求；
- “三四年”是原文的近似时长，不是精确三年或四年阈值；
- “良好流年”没有独立判定标准；
- 前置 CA09-850 的上下文仍需单独验证。

所以它不是普通的单年触发，也不能转成通用 PERSISTENCE / GOOD_YEAR 算子。

### 5.2 TP03-248：同年先决分支与事件后果

来源：SRC-ZZ-003，田宅宫印刷 p163 / PDF 物理 p82。

- 这是同年条件分支；
- “前格见吉”承接前一年度结构；
- 后面的事件后果不能倒过来证明事件已经发生；
- 前件 TP03-247 仍是 CASE_SUPPORT_ONLY。

它与 CA09-851 的多年连续窗口不是同一种机制。

### 5.3 否定条件与吉凶词

GAP-011 已经确认：原文“不见吉曜/不见煞”是特定上下文中的来源分支，但不等于系统没有观测到某个正向事实。因此不能使用全局封闭世界假设。

GAP-006 也已明确区分类别成员、激活方式、关系、交互和期间吉凶；“良好流年”“见吉”不能直接形成通用 GOOD_YEAR 或吉曜全集。

## 六、历史记忆与事件相对时间不能混层

A2-R1 已批准：

- `D_t`：来源明确说明形成、强化、削弱或保持的后天倾向；
- `H_t`：过去事件/阶段改变后续资格或分支的路径门控。

两者不能互换；没有明确 persistence 范围就只能写 unspecified，不得补数值衰减率。

迁移后三年窗口则是另一种结构：必须由外部提供“已确认远迁定居”和已过年数。它不是后天性格记忆，也不能推广为所有事件的通用计时器。
