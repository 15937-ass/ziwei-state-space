## 3. 规则行级审查结果

### 太阴（5 条）

- `ZZ-TYI-002` 是本批最清楚的直接基调描述：潜藏与收敛。它支持源文描述，但不直接决定现代 QI-01 的量值。
- `ZZ-TYI-006`、`ZZ-TYI-007`、`ZZ-TYI-008` 是彼此关联但方向不同的条件分支：过度收敛可在太阳满足条件时改善；入庙吉化时适度收敛；特定发射/杂曜条件下则可能“内涵空虚不实”。不能只保留其中一支。
- `ZZ-TYI-X08` 明确依赖空劫同度，原文用“每多”“每易”而非绝对断言。

### 贪狼（4 条）

- `ZZ-TL-002` 来自初级讲义简表的“化桃花”传统分类，不能直接等同现代心理变量。
- `ZZ-TL-008` 明确依赖“独坐”，原文只说“有……倾向”。
- `ZZ-TL-X01` 将物欲与情欲并列，且原文提醒不能笼统只称桃花；`ZZ-TL-X02` 解释变化动机与欲望追求有关，不表示变化必然发生或成功。

### 巨门（3 条）

- `ZZ-JM-002` 的“暗曜”有明确解释背景“土静金埋”，并指向遮蔽/是非口舌语义；不能简化成道德负面。
- `ZZ-JM-004` 单独保留口才描述；化权、格局和太阳会照等后续条件不可折叠进无条件结果。
- `ZZ-JM-X01` 描述多言及自我表现，与“口才”相邻但不是同一概念，也不等于认知机变。

### 天相（2 条）

- `ZZ-TX-001` 与 `ZZ-TX-X02` 都强调环境支配和夹宫/同会关系；当前两条均被引用到 intrinsic QI-02，但源文首先支持的是上下文依赖。
- 两条有同段语义重叠，不应视为两份独立来源证据。本轮只提出研究性重分类建议，不修改 canonical core。

### 天梁（6 条）

- `ZZ-TLIA-002` 的“监察御史”是传统职官比喻；`ZZ-TLIA-003` 随即说明天梁“不主管刑法”，只说带刑法、纪律、原则意味。
- `ZZ-TLIA-004` 与 `ZZ-TLIA-X01` 描写孤忌/独行与原则性；`ZZ-TLIA-X01` 是同时被用作 QI-10 与 QR-01 的复合主张，不是两份独立证据。
- `ZZ-TLIA-006` 支持按原则排解纠纷、判定是非，但同段也指出因此可能卷入困难。
- `ZZ-TLIA-X05` 明确依赖四煞，并提出文昌文曲的调和条件，不能上升为无条件孤忌。

### 七杀（5 条）

- `ZZ-QS-002`、`ZZ-QS-X02` 都使用七杀主帅、破军先锋的对照；“主帅”是相对角色比喻，不能直接当作现实领导力值。
- `ZZ-QS-004` 与 `ZZ-QS-006` 分别支持掉臂独行和刚克的源文描写，后者仍受文曜/辅佐等条件修订。
- `ZZ-QS-010` 明确要求详查天府稳重与七杀冲刺的相互影响，属于关系性证据而非脱离天府的单星绝对量值。

### 破军（8 条）

- `ZZ-PJ-002`、`ZZ-PJ-003`、`ZZ-PJ-X01` 指向“冲锋而不主退守”的相同/近似源文内容。按规则 ID 保留三行，但不计为三份独立来源证据。
- `ZZ-PJ-003` 与 `ZZ-PJ-X02` 明确以“破军守命”为条件；`ZZ-PJ-X02` 的受职情境也必须保留。
- `ZZ-PJ-004`、`ZZ-PJ-005` 与 `ZZ-QS-X02` 同属七杀—破军比较段；“劳心/劳力”“受命于主帅”不能脱离比较关系。
- `ZZ-PJ-X06` 存在重要的条件范围差异：扫描原文支持“不得禄，或见煞忌刑曜重”时叛逆性较大；canonical 条件写成“无禄无权且无辅佐反见煞忌”，更具体，且把源文的“或”改成更强合取。本轮只记录差异，不修订 canonical 条件，也不将其宣称为已逐字验证。
- `ZZ-PJ-X10` 支持“旧事创新”及与旧事有关的变化解释，不表示所有变化必然成功。

## 5. 跨行问题与后续顺序

1. **角色与证据层级分轴**：直接来源可以支持条件性或关系性主张；不能因来源直接提到某星就自动当作 intrinsic。
2. **文本重叠**：贪狼/巨门/天相/天梁/七杀/破军若干规则引用同一段或同一句。CSV 按唯一 rule ID 记录，不把重复引用当作独立证据。
3. **条件保真**：保留“若”“当……之时”“不见……则”等条件、比较对象与倾向措辞。
4. **本批不做 QI/QR overlap audit**：待十四主星全部完成来源优先审查后，再单独开启重叠审计工作单。
5. 本报告不接受任何 QI/QR 映射，不增加 ontology ID，不改变 canonical 源规则、星核、星系模型或 Product。

## 6. 解释限制

本审查验证的是来源片段与研究分类的可追溯性，不证明传统星性分类具有唯一解释，不证明 QI/QR 映射正确，不证明十四主星性质空间完备，也不证明现实预测有效。概率、权重、阈值与经验有效性均不在本工作单内。
