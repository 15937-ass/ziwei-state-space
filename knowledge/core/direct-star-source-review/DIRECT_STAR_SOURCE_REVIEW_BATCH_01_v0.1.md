## 1. 研究边界

本轮只审查来源支持、对象是否对齐、证据层级和语义角色。不是本体定案，不接受 QI/QR 映射，不改变运行时。所有规范化判断继续为 `UNRESOLVED`；canonical 规则行中原有的 `source_span_verified=false` 也不在本工作单中修改。行级表的 `VERIFIED_VISUAL_SCAN` 只记录本次审查对原扫描页的核对结果。

行级 CSV 同时保留 canonical `source_epistemic`、原始 condition/time_scope/palace_scope、prerequisite/exclusion/conflict IDs、operator/state_change/valence/applicability_scope，以及原始 `source_span_verified=false` 状态。研究审查中的 `VERIFIED_VISUAL_SCAN` 与 canonical 原始标记分列保存；不把本轮核对结果直接写回 canonical 规则库。

## 2. 来源核对方法

1. 核对仓库 canonical 规则行、source locator 和 `star_cores.yaml` 的实际引用位置。
2. 对照与 source registry SHA-256 一致的已上传原扫描 PDF，检查对应扫描页；行级表只记录短的、已核对的原文片段。
3. 将源文主张分别归为 `INTRINSIC`、`RELATIONAL`、`CONDITIONAL` 或 `UNRESOLVED_OTHER`。这与 `evidence_tier` 分开：直接提到某颗星，不代表该句证明了无条件内在性质。
4. 记录当前 tier 与研究建议 tier；所有建议均为研究性，不修改 canonical `star_cores.yaml`。
5. 保留原文条件、比较对象、时间/宫位范围、语气和反例；不把“往往”“吉则/凶则”、相较另一星或星系交互改写成必然事件。

## 4. 分星发现

### 紫微（4 条）

- `ZZ-ZW-015`、`ZZ-ZW-018`：原文分别依赖魁钺会合与昌曲会合，支持的是条件性修饰/关系，不是无条件的主导性内核。建议将证据放入条件层审查。
- `ZZ-ZW-X01`、`ZZ-ZW-X05`：先有“落陷且无百官朝拱”的在野孤君条件，再区分见空曜与不见空曜时的不同后果。不得将六亲无靠与是非纷扰合成一个普遍结果。
- 现有紫微 `intrinsic_signature` 为空不构成缺陷；本轮证据不授权填入固定性质向量。

### 天机（3 条）

- `ZZ-TJ-002` 明确说天机需要聪明才艺性质星曜会合；`ZZ-TJ-005` 明确依赖昌曲相夹。两条不能单独证明天机具有无条件的高认知机变，建议从当前内在基线引用中移出并按条件证据处理。
- `ZZ-TJ-X01` 的“谋士/军师”是直接的传统比喻，但不能仅凭这个比喻就确认 QI-07 的具体维度值或完整向量。

### 太阳（7 条）

- `ZZ-TY-002` 是本批清楚的直接基础描述：发射光和热。
- `ZZ-TY-009`、`ZZ-TY-016`、`ZZ-TY-017` 是入庙、过强或不足等条件下的平衡规则；`ZZ-TY-018` 更接近一般解释方法中的中和原则，是否应归入单星气核仍待审议。
- `ZZ-TY-010` 与 `ZZ-TY-X02` 指向同一原文句“光与热扩散太过，更易流为空虚而欠沉实”，却使用不同 target/normalization。不得将二者算作两份独立来源证据；需要另行审查重复、拆分和目标语义。

### 武曲（6 条）

- `ZZ-WQ-004` 直接描述行动与具体；该 ID 同时被 QI-05 和 QI-08 引用，但仍然只是一条来源规则，不是两份独立证据。
- `ZZ-WQ-005` 直接支持刚烈倾向；`ZZ-WQ-003` 是武曲与太阴的比较，不能脱离比较关系作为独立绝对值。
- `ZZ-WQ-006` 把刚烈与六亲孤克相连，但原文强调宫垣不同、评价不同；只能作为带宫位门控的关系主张。
- `ZZ-WQ-019` 依赖昌曲成对会入，并包含“柔和”与“优柔寡断”的 trade-off；`ZZ-WQ-024` 明确属于武曲见破军的星系交互，应进入系统上下文/模态审查。

### 天同（6 条）

- `ZZ-TT-002` 将天同称为南斗中最和气者；这是有来源的比较性描述，不等于可量化的绝对 QI-02 值。
- `ZZ-TT-004`、`ZZ-TT-005` 在初级讲义简表中仅为“吉则享受、凶则软弱”；现有条件字段把“吉/凶”细化为吉化/吉曜或凶曜/失衡，属于更具体的归一化，不能冒充原文逐字条件。
- `ZZ-TT-006` 的“善化凶”确实见于来源简表，但将其映射为 QI-15 缓冲/化解能力仍未获确认。
- `ZZ-TT-X01` 使用“往往”“象征”描述挫折后得福的过程倾向，不是保证某人一定先经历挫折再获福。
- `ZZ-TT-X02` 是与贪狼对比后描述主动争取倾向，不能单独变成天同的绝对行动驱动低值。

### 廉贞（2 条）

- `ZZ-LZ-003` 原文确有“廉贞是属于感性的星曜”，但所在章节是“化禄·廉贞”；同段随即讨论化禄时精神享受多于物质享受，引用时应保留这个章节语境。
- `ZZ-LZ-Y01` 讨论理智与感情调和/冲突的条件性后果，不能把“调和”本身当成廉贞恒定的内在性质。

### 天府（5 条）

- `ZZ-TF-002` 直接给出“财库”比喻，同时明确天府本身并不是财星；“资源储藏/管理”是解释性归一化。
- `ZZ-TF-003` 与 `ZZ-TF-004` 分别支持运用/储藏财帛与缺乏生财能力的对照，不能把这类传统描述外推为现实个体的财富预测。
- `ZZ-TF-005` 与 `ZZ-TF-006` 都是相对紫微的比较。前者支持守成与开创的相对关系，后者支持领导/决断力相对差异；均不表示天府没有领导力或守成是脱离比较对象的绝对量值。

## 5. 跨行问题与后续建议

1. **层级错位**：直接来源、内在性质、关系性质、条件反应和系统交互不是同一轴。应先修正研究分类，再讨论是否调整 `star_cores.yaml`；本轮不做 canonical 修改。
2. **重复证据**：`ZZ-TY-010` 与 `ZZ-TY-X02` 有明显原文重叠；`ZZ-WQ-004` 在气核中被多维引用。统计时应按唯一 source-rule ID 计数，而非按引用次数计数。
3. **条件细化**：`吉则/凶则`、庙旺、会合、夹宫、星系等条件必须原样保留。若后续归一化增加了原文没有的条件，应标为透明推断或未解决。
4. **不变边界**：所有 33 条的 `normalization_epistemic` 仍为 `UNRESOLVED`。本报告不接受 QI/QR 映射，不增加 ontology ID，不改变 canonical 源规则、星核、星系模型或 Product。

## 6. 精确覆盖

本批 CSV 应当恰有 33 行规则记录、33 个唯一 rule ID，按 Issue #720 指定的七颗主星与 ID 清单覆盖；任何一个 ID 都不重复。
