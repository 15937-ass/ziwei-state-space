# BAIGUAN SUPPORT PROFILE v0.1

Issue: #469  
Status: **结构本体冻结；统一成立阈值不批准**

本对象只针对 **紫微 anchor**。

## Source-backed 组件

- 正曜支持：天府、天相。深造讲义明确“正曜朝拱须天府天相始为合格”，但这只是正曜分支的合格条件，**不能反推府相二曜单独就等于完整百官朝拱**。
- 辅曜：左辅右弼、天魁天钺。
- 佐曜：文昌文曲、禄存天马。
- 杂曜：三台八座、恩光天贵、台辅封诰、龙池凤阁、天福天寿。
- 化禄、化权、化科：source 明确“不称为朝拱”，只作其他改善/修饰。

## Quality guards

天府是否为空库、天相是否财荫夹/刑忌夹/羊陀夹，都会影响 component quality。因此“成员存在”不能直接等同“有效支持”。

## Source tension

初级讲义把“百官及群臣”主要表述为辅佐杂曜，并把府相朝垣另说；深造讲义则把正曜分支纳入百官 taxonomy。v0.1 依照已批准 Human Gate 使用深造讲义 taxonomy，但保留这处表述差异，禁止把百官压成一个扁平星曜袋。
