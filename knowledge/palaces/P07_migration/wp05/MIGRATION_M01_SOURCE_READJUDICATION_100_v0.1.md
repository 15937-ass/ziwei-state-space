## Main semantic result

The Migration Palace is not a one-step “away = good/bad” lookup.

The source establishes this chain:

```text
natal Migration nature
-> movement-signal detection
-> voluntary / related-palace involuntary trigger
-> temporal context
-> post-move star-system evaluation
-> external support / opportunity / pressure / resource / relation / career outcome
```

A movement signal is not automatically a favorable outcome. In particular, 禄马交驰 can support a movement reading while the actual post-move result remains adverse when the surrounding structure is adverse.
