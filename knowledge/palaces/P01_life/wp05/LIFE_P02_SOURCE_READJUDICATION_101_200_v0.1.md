# 命宫 P02-101…200 Source Re-adjudication v0.1

本批继续重建命宫 canonical corpus，将历史候选 **P02-101…P02-200** 重新逐条回到 SRC-ZZ-003《中州派紫微斗数深造讲义（下册）》命宫章印刷页 6–9 复核。历史编号中的 P02 只是旧 checkpoint 编号，宫位身份仍是 P01 命宫。

## 结果

- 100 / 100 已直接回源复核。
- 70 条保持为可复用 projection / state / timing / constraint 知识；30 条保持 `CASE_SUPPORT_ONLY`。
- 18 条修复了时间范围、一般规则被例子污染、跨宫关系、抽取缺字或历史候选字段异常。
- P02-125、P02-130 删除了由后续例子反推出来的固定事业宫/迁移宫依赖。
- P02-164 修复旧候选中空白的 case-support 字段，并保留父母宫太阳条件及原文抽取疑字。
- P02-168/169、177/178 的“人生枢纽”不再被静默等同为单一 DECADE 层。
- P02-170 的“少年运程之优劣可以影响一生”只挂接既有 history schema 候选，不新增记忆类型。
- P02-190 把“对宫天马”保留为对宫关系，不重复泛化成普通迁移宫依赖。
- P02-199 恢复“须详兄弟宫吉凶”的显式跨宫门控。
- 具体目疾、消渴/糖尿病、水险、死别、婚姻等仍停留在有源的事件候选层。

## 本批对命宫模型的推进

这一段把命宫的状态空间结构进一步坐实：太阳段同时受庙陷、昼夜、巨门/天梁所在宫度、煞曜、父母支持与运限枢纽影响；武曲段则把“生财行动”、辅佐结构、合作条件、火铃的条件性激发与危险结构区分开来。也就是说，命宫不是单一性格向量，而是**原局本质 + 条件门控 + 时层枢纽 + 跨宫约束 + 场景投影**的组合系统。

特别是火铃：在丑未武贪可成为正向激发条件，但武贪化忌后再见火铃又按见煞论。因此本批再次否定“某曜永远加分/减分”的统一标量捷径。

## Source-coverage gaps

本批在印刷页 6–9 额外识别出 18 个历史抽取缺口，包括：
- 巳亥天机的大限/流年枢纽；
- 子午、丑未、寅申、卯酉、辰戌、巳亥太阳若干整段枢纽与条件；
- 武府、武贪、武相、武杀的遗漏枢纽；
- 辰戌武曲继承武贪性质与年限枢纽；
- 若干传统性别化、职业化与具体应象条目。

这些缺口已经写入 summary，下一 checkpoint 会先补齐再继续进入天同，不因旧 100 条边界而跳过源文。

本批不触发 Human Gate，也没有新增 primitive qi、概率、数值权重、阈值、衰减或独立时间尺度。
