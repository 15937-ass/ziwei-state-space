## 3. 当前状态含义

本工作包完成的是**目录级/页段级 coverage inventory**。

这不表示所有 coverage unit 都已经抽取规则。

状态解释：

- inventory：已经识别页段，但尚未抽取
- partial：已有代表性或架构性规则，但未全文穷尽
- reviewed：方法论页段已用于冻结结构并完成审查
- complete：需满足 `KB_COMPLETENESS_CRITERIA.md`

## 4. 为什么 coverage matrix 是知识库完整性的基础

以后不能通过“规则数量很多”宣称知识库完整。

例如：
- 十四正曜目前已有200条规则；
- 但只有逐颗星 page-bounded coverage unit 全部双遍审查后，才可声明 star-core domain complete。

同理：
- 六十星系已有60项索引；
- 但未逐项穷尽四化、辅煞、案例与运限规则，所以仍为 partial。
