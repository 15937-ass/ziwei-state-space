## 三、本组对模型最重要的反馈

### 1. principal mode 具有明确的中尺度状态特征

第三组出现：紫府主动/被动、太阴意志坚强/薄弱、贪狼坚忍/躁进、巨门深沉/冲动、廉相刚毅/脆弱、天梁正直/精明、七杀孤高/威权、天同充实/空虚、武曲因循/进取、太阳积极/消极、破军顽嚣/果敢、天机上进/下游。

这些词多数不能直接成为 primitive qi，因为它们往往由多个基础状态和跨星系条件共同决定。

### 2. 好环境并不总是产生好结果

多处规则显示：因循武曲在良好紫府运中可能更依赖安逸；下游天机在良好太阳运中可能安于现状；消极太阳遇好机会仍需主动改变才可利用；顽嚣破军遇好运也可能自己破坏运势。

因此后续模型必须保留 outcome = f(natal essence, mode, input, response)，不能退回 good input -> good outcome。

### 3. 同一结果、不同机制反复出现

例如破军行太阴化忌：顽嚣者多自发妄作，果敢者可能因受怂恿而误事。这支持将 mode 与 reaction mechanism 分开。

### 4. 路径依赖证据进一步增加

本组多个系统明确提到：某大限形成的冷退/因循/顽嚣会影响后运；当前良运若利用不当，会改变后续表现；天机系统甚至要求评估后续数个流年后再决定是否创业。

这些证据支持 future historical_context_t 变量，但仍不重开G5。Paper 1主模型继续保持原局本质 + 当前时序输入 -> 反应，路径依赖只作为后续扩展接口。

### 5. 后天行为在文本内部具有明确调节作用

第三组多次出现守成/进取、退居幕后、选择合作伙伴、不弄权、不走捷径、改变因循、慎选发展目标等。说明未来 u_t^human 与 u_t^astro 分开是必要的。

但传统建议不能直接当作现代因果控制策略；真正 controllability 仍需外部因果数据。
