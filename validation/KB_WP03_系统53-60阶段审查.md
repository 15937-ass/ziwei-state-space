## 三、对模型最重要的反馈

### 1. 六十星系最后一组进一步证明“中间模态”不能压成吉凶分值

权威/横霸、奉公/私利、欲望/野心、正直/徇私等，都描述“系统如何组织同一股驱动力”，而不是简单的强弱。

因此星系层应继续表示为：

```
z_s = M_s(q_stars, modifiers, structure)
```

而不是：

```
z_s = scalar_goodness
```

### 2. 同一吉曜可以改变结果，却不一定改变本质

例如：
- 紫微七杀中，破军化禄可改善事业声势，但权威/横霸仍由更完整结构决定；
- 廉贞破军中，天府得禄可能让奉公者建立方向，也可能让私利者结党营私；
- 天府巳亥中，良好运对权术型可能只是暂时得利；
- 天相卯酉中，天府得禄可帮助正直者掌事，也可能放大徇私者的滥权风险。

因此必须严格区分：
- natal/system mode
- situational gain
- observable outcome

### 3. “人的反应”再次成为显式中介

本组大量规则包含：
- 持盈保泰；
- 不妄动；
- 不辜负支持；
- 不弄权；
- 守成；
- 离乡或不离乡；
- 是否牺牲朋友利益。

这些内容支持未来显式建模 human response，但不能把传统趋避建议直接当作已验证的因果控制律。

### 4. 系统60提供了最接近“原局状态 × 运限输入”的文本证据

机梁章节明确要求判断运限四化是：
- 加强原局调和；
- 还是加强原局矛盾。

并给出同向加强与反向破坏的具体例子。

这与我们冻结的 state-dependent reaction 结构高度一致，但仍属于传统文本内部形式化证据，不是经验有效性的证明。
