## 二、G5 最重要的模型选择

### G5-1：Paper 1 主模型不用“逐年递推状态”作为核心

建议正式冻结：

~~~text
E = BuildNatalEssence(chart_0)

U_t = BuildTemporalInput(chart_t)

R_t = React(E,U_t,Z_t,G_t,C_t)

Y_t = Project(R_t,C_t)
~~~

含义是：

1. 原局先形成固定本质 E；
2. 大限/流年形成外生时序输入 U_t；
3. 输入作用于原局本质，形成当期反应 R_t；
4. 反应经过宫位与现实上下文投射为 Y_t。

这是当前最忠实于中州派“原局本质—后天反应”逻辑的形式。

### G5-2：真正递归动力学只作为以后可检验假设

保留：

~~~text
x_(t+1)=F(x_t,E,u_t,z_t,G_t,c_t)+w_t
~~~

但明确标记为：

> HYPOTHESIS / future extension

不能说这是中州派原文明示的定律。

是否需要递归状态，未来由纵向命例数据判断。

## 三、十二宫状态组织

建议冻结为：

> **12 个局部宫位本质 + 一个全局稀疏关系图**

形式：

~~~text
E = {e_1,...,e_12}
G = (V_palace,E_graph)
~~~

这同时满足：

- 每宫有自己的原局本质；
- 三方四正与跨宫依赖仍能传播信息；
- 不把十二宫当成完全独立系统；
- 不把所有内容压成一个无结构 global vector。

## 四、输入类型必须严格分开

### 外生时序输入
~~~text
u_t^astro
~~~

包括：
- 大限；
- 流年；
- 四化；
- 当期星系结构。

它们不是 control input。

### 人类行为输入
~~~text
u_t^human
~~~

例如未来研究：
- 是否投资；
- 是否迁移；
- 是否合作；
- 是否就医；
- 是否转职。

只有以后有因果/干预数据，才讨论 controllability。

### 外部扰动
~~~text
d_t
~~~

包括：
- 社会环境；
- 经济；
- 家庭事件；
- 公司政策；
- 随机事故等。

三者必须分开，避免把“命盘时间信号”和“人的选择”混为一谈。

## 五、“气 -> 象 -> 事”正式形成完整链条

建议冻结：

~~~text
符号结构
 -> 潜在气机
 -> 星系模态
 -> 宫位反应
 -> 场景投影
 -> 语义结果类别
 -> 现实观察事件
~~~

明确禁止：

~~~text
某颗星 -> 某个具体事件
~~~

这一步意味着我们最早讨论的“同一种气可以有多个应象”已经正式进入模型结构。

## 六、结构能观性

Paper 1 当前没有 A/C 数值矩阵，所以不能计算经典：

~~~text
rank(O)
~~~

建议冻结为“结构能观性/可区分性审计”。

判断一个气机变量是否有：

~~~text
qi
 -> 星曜/星系规则
 -> 宫位反应
 -> 场景投影
 -> 独立输出通路
~~~

当前结果：

### 结构通路较充分
- 发射—收敛
- 刚—柔
- 稳定—变动
- 守成—开创
- 现实化—空泛
- 认知机变
- 行动驱动
- 欲望驱动
- 原则约束
- 资源管理
- 表达传播
- 缓冲调和
- 关系整合—孤离
- 主导—协同

### 部分可观，需要后续继续检验
- 决策激活度
- 感性—理性张力
- 遮蔽—显明
- 竞争激活
- 支持资源

没有发现当前正式核心变量完全没有输出路径。

但这只能叫：

> structural observability audit

不能写成：

> 已证明系统完全可观。

## 八、observer / 能控性如何处理

### Observer

未来可以研究：

~~~text
预测状态
 + 现实观察误差
 -> 更新潜状态估计
~~~

例如 Kalman-like observer。

但 Paper 1 不执行真实人生状态滤波。

### Controllability

Paper 1 不做真正能控性分析。

理由：
- 大限流年不可控；
- 人类行为与结果之间尚无因果辨识；
- 不能用相关命例直接推出最优“趋吉避凶”行动。

因此只保留未来接口。
