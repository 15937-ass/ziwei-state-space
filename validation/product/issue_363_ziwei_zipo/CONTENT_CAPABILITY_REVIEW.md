# Issue #363：八条规则的产品内容能力审查

本文件说明这批规则在产品中实际增加了什么判断，以及哪些结论仍不能给出。
它不增加规则数量，也不把来源性质升级为现实预测。

## 一、紫微守事业宫：责任形态，不是身份标签

CA01-047 与 CA01-050 在事业宫见紫微时共同成立，但回答不同问题：

- CA01-047 表达适合独当一面的责任性质；
- CA01-050 表达独立工作，或负责一个部门的工作形态。

两条都不能推出当事人一定自行经营、已经成为领袖、现实中必然担任管理者，
也不能据此判断具体职业或组织层级。产品应把它们显示为责任与工作形态的
来源倾向，而不是身份预测。

## 二、丑未紫微破军：开创、资源投入与守成差异

CA01-083 与 CA01-093 构成这一星系的基础层：

- CA01-083 表达事业取向偏开创而不偏守成；
- CA01-093 表达经营规模或资源投入可能大于实际收成。

这两条只在事业宫为丑或未、紫微与破军同宫时成立。CA01-093属于本段总范围，
不额外要求破军化禄，也不等于真实亏损、创业失败或收入预测。两条结合后，
产品可以描述“重开创、投入与回收可能不对称”的结构特征，但不能把它写成
具体事件或财务结论。

## 三、破军化禄与化权必须分开

破军化禄时，CA01-087 与 CA01-088 在基础层之上增加两项不同内容：

- 事业变化较多；
- 常有额外工作或同时承担多项责任。

二者都继承丑未紫微破军范围，CA01-088还必须完整继承破军化禄，不能只看到
“前格”就简化为紫微破军。产品不能据此预测何时换工作、变化次数或具体工作量。

破军化权时，CA01-089表达事业发展中的波折性质。它不能借用化禄分支的多变或
额外工作结论，也不能断言某次挫折必然发生。产品报告必须把化禄与化权作为两条
不同的解释路径。

## 四、左辅右弼：支持条件必须完整

CA01-095表达开创事业时较易获得助力，但前提是紫微、破军、左辅、右弼都在
丑或未的事业宫。同见一颗辅曜、辅曜落在其他宫位，或仅有对宫会照，都不能代替
这条完整条件。它表示来源中的支持倾向，不表示现实中一定有人帮助或事业成功。

## 五、产品组合后的可回答范围

| 命盘结构 | 产品可以表达 | 产品不能表达 |
|---|---|---|
| 事业宫见紫微 | 独当一面的责任倾向；独立工作或部门负责的形态 | 自营、领袖身份、具体职位 |
| 丑未事业宫紫微破军 | 偏开创；投入规模与实际收成可能不对称 | 创业成败、真实收入、亏损金额 |
| 上述结构且破军化禄 | 变化较多；额外工作或多重责任 | 变动时间、次数、必然换职 |
| 上述结构且破军化权 | 发展过程较有波折 | 某项挫折必然发生 |
| 上述结构且左右同宫 | 开创时获得助力的倾向 | 必然得到帮助或成功 |

这些内容均属于本命静态性质。生产时层注册表为空，因此当前产品不能给出事件时间、
流年触发、概率、因果关系或经验准确率结论。

## 六、下一批二十条的只读产品预审

Knowledge #366新增的二十条完整条件映射尚未进入产品。本次只读检查确认其条件都能由
现有星曜、地支、四化和对宫事实表达，可按内容分为三组：

1. 子午紫微与既有紫破延伸（6条）：业务管理责任、夫妻协作、夫妻合作事业边界、
   对立／树敌倾向、公共政治事业适配限制，以及开创过程较劳累。
2. 寅申紫微天府（7条）：白手兴创与依托既有平台的差异、理想与财力容量的落差、
   脱离实际的策略风险、工业场景可能性及竞争模仿压力。
3. 卯酉紫微贪狼与辰戌紫微天相（7条）：消费市场取向、合作持久性、空劫下的基础
   虚浮与波动、号召力和组织力的差异、团队基础及事业起跌倾向。

其中夫妻关系、政治事业、敌对关系、合作破裂和具体行业最容易被产品文案写成现实
事件或确定职业，需要继续保留“场景适配／来源倾向”措辞。二十条的来源上下文结构
也不同于当前八条，后续接入应先建立独立、严格的上下文契约，再分组验证；本Issue
不自动激活这些规则。
