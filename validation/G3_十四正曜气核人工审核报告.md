## 二、十四正曜当前核心气核摘要

### 紫微
- 核心：主导/统摄倾向
- 特征：高度依赖百官朝拱、孤君等结构
- 当前不足：“统摄/组织”可能值得独立成为新气机维度，暂留到 G4 检验

### 天机
- 核心：认知机变、变化性
- 条件：化权加强用世，空劫易使变化流为空想
- 重点：本命人格本质与运限变化必须分开

### 太阳
- 核心：发射、显明
- 条件：过强需收敛，过弱需发射补偿
- 重点：典型非单调“中和”结构

### 武曲
- 核心：刚烈、具体、行动
- 关系：带孤克
- 条件：不同宫位对同一刚性评价不同

### 天同
- 核心：柔和、缓冲/化解
- 次级：享受倾向
- 风险：柔和不能直接等同于软弱

### 廉贞
- 核心：欲望/感性驱动、感性—理性张力
- 条件：星系组合可向和缓或躁决方向转化

### 天府
- 核心：资源保存/管理、守成
- 次级：调和刚烈
- 风险：空库/露库属于状态转化，不是简单“凶”

### 太阴
- 核心：收敛、潜藏
- 条件：适度收敛、过度收敛、发射破坏构成非单调结构

### 贪狼
- 核心：欲望驱动
- 条件：物欲、情欲、自律、审美、投机等存在子结构
- G4 需检验是否建立“欲望类型向量”

### 巨门
- 核心：遮蔽/阴暗 + 表达/传播
- 条件：辅弼昌曲可把疑忌、多言转为思虑、善辩
- 重点：“是非口舌”属于关系/输出，不是 primitive core

### 天相
- 核心：柔和、调和
- 特征：上下文依赖极高
- 风险：柔和和软弱必须分开

### 天梁
- 核心：原则/规范、孤忌
- 次级：纠纷调处、独立
- 特征：同一太阳天梁可分祥和、孤忌两种本质

### 七杀
- 核心：刚克、冲刺、独立行动
- 关系：统帅/主导
- 特征：紫微等条件可“化杀为权”

### 破军
- 核心：变动、突破/冲锋、行动驱动
- 条件：化禄改善变动过程，化权主要增强声势但不保证结果
- 重点：证明“驱动力”和“结果质量”必须分开

## 三、本轮最重要的理论升级

### G3-1：星曜气核必须是“基态”，不是完整命理解释

建议以后正式写成：

```text
S_i^0 = 第 i 颗星的基础气核
S_i(c) = T_c(S_i^0)
```

其中 `c` 表示上下文，`T_c` 是条件修正算子。

这意味着：

> 单星只提供初始潜状态，真正表现必须经过星系、辅煞化曜、宫位与运限作用后才能得到。

### G3-2：六十星系不能做简单向量相加

下一阶段建议明确采用：

```text
H_ij = Phi(S_i, S_j, context)
```

而不是：

```text
H_ij = S_i + S_j
```

因为现有材料已经出现明显交互项：
- 武曲+破军：刚烈转躁决；
- 太阳+天梁：可分祥和与孤忌；
- 天相受夹宫可将软弱转能力或进一步恶化；
- 紫微破军对四化异常敏感。

因此 G4 的核心将是识别：

```text
interaction_delta
```

也就是“星系涌现性”。

## 四、建议 G3 冻结的内容

建议批准并冻结以下原则：

1. 十四正曜统一采用  
   **L0结构底座 + L1内在气核 + L2关系气核 + 条件修正层**。
2. 星曜气核只是基态，不等于完整解释。
3. core / secondary / conditional 只表示文本核心程度，不是经验数值权重。
4. 财富、疾病、婚姻、名誉、成功失败等不得进入 primitive star core。
5. 本命星曜性质与运限表现必须分层。
6. 六十星系阶段必须允许非线性交互项，不能只做单星相加。

## 五、本次不建议冻结的内容

以下内容继续保留修订权：

- 每颗星具体维度是否已经穷尽；
- 每个维度未来的真实数值权重；
- “统摄/组织”是否新增为独立气机；
- “欲望类型”是否拆成多维；
- “敏感/踏实”等星系级状态是否反向进入单星本体；
- context_sensitivity 最终如何参数化。
