# Internal Reconstruction Cases v0.1

## 使用原则

这些案例只用于验证：

> 本项目形式化是否能重构中州派教材自身的推断依赖结构。

它们不用于证明现实预测准确率。

---

## Case 1：同一大限结构作用于不同原局本质

### 原书逻辑

《深造讲义（下）》宫垣论前言给出连续对比：

- 原局紫微午宫、带“泛水桃花”性质者，顺行到未宫见天同巨门、巨门化忌等，反应为感情困扰与是非；
- 同样紫微午宫，但原局为“孤君无道”本质者，遇相似未宫运限结构，反应会转成“因财招不利/错误从事影响一生的事业”；
- 天机巳宫、天机化权与禄存同度者，行到相似乙未结构，又表现为“投资进财过程中受人影响作错误决定而损失”。

### 当前模型重构

~~~text
same/similar U_t
+
different natal essence E
- E_A: 桃花型紫微
- E_B: 孤君型紫微
- E_C: 天机化权型
↓
R(E_A,U) != R(E_B,U) != R(E_C,U)
~~~

### 验证结论

PASS。

该例直接支持 Paper 1 的核心结构：

~~~text
R(e_a,u) != R(e_b,u)
~~~

并反对“只看当前大限三方四正”的机械模型。

## Case 2：原局子女宫本质 + 运限刺激

### 原书逻辑

《深造讲义（上）》武曲天府案例：

- 原局子女宫武曲天府，铃、陀等使其具有“偏弊之性”；
- 后行戊戌运时，子女宫借对宫太阳太阴安星，同时出现大运四化等条件；
- 讲义把后运中的散财/子女相关结果，明确追溯到“原局子女宫武府具偏弊之性”的基础。

### 当前模型重构

~~~text
e_子女 = E(武曲天府原局 + 铃陀 + 夹宫结构)

u_(子女,t) = U(戊戌运星系 + 当期四化)

r_(子女,t) = R(e_子女,u_t,z_t,...)

y_(子女,t) = P_子女(r_t,现实上下文)
~~~

### 验证结论

PASS。

模型可保存“原局宫位本质”与“后运刺激”两个不同对象，不会让流年结构覆盖/重写原局。

## Case 3：事业/财帛不能孤立投影

### 原书逻辑

《深造讲义（下）》财帛宫材料明确通过财帛宫与事业宫组合来判断求财性质与行业倾向，并举：

- 财帛宫太阳；
- 事业宫天梁；

即使太阳化禄，也不能只按财帛宫“见禄”推出经商最优，而要受事业宫天梁的行业/服务性质影响。

同段还讨论：
- 财帛宫吉、事业宫不吉；
- 或事业宫显、财不聚；

会形成不同的职业经营策略。

### 当前模型重构

~~~text
Y_career_resource =
P_domain({
    h_财帛,
    h_事业,
    h_命,
    optional(h_福德)
}, C_person)
~~~

而不是：

~~~text
Y = P_财帛(h_财帛)
~~~

### 验证结论

PASS。

支持“十二宫局部节点 + 跨宫稀疏图”的 G5 选择。

## 总结

三类教材逻辑分别验证了：

1. state-dependent reaction；
2. natal essence / temporal input separation；
3. cross-palace graph projection。

这些是**内部语义保真测试**，不是现实预测实验。
