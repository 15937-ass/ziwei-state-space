## 二、最重要的红队结论

### 1. 六十星系“本质判别词”不能直接变成六十组新气机维度

如果每看到：
- 祥和/孤忌；
- 有情/无情；
- 坚忍/躁进；
- 权威/横霸；
- 明断/尖刻；

就新增一个 primitive qi，状态空间会迅速膨胀，而且大量变量只是已有基础状态的组合结果。

例如：
- “明断/尖刻”可由认知机变、原则约束、决策激活度及平衡关系共同生成；
- “权威/横霸”可由主导、原则约束、支持资源、竞争激活共同生成；
- “统筹”可由行动驱动、资源管理、主导/协同共同生成。

因此红队支持引入**星系模态 z_s**，把这些高层判别保留在中尺度，而不是污染 primitive ontology。

### 2. 星系交互确实不能预设为简单加法

多处原文说明：
- 同一基础倾向过强、过弱均可能失衡；
- 条件星曜会改变组合后的性质类别；
- 同一星系会在不同条件下进入不同“本质”。

典型例：
- 武曲天相：不是“刚 + 柔”的静态相加，而是要求刚柔调和；
- 紫微天府：紫微开创 + 天府守成，平衡时出现“攻守咸宜”；
- 紫微破军：辅佐、四化、三合结构可使其在安定/动荡之间切换；
- 天机天梁：敏感变动与原则纪律平衡为“明断”，冲突则为“尖刻”。

因此至少应保留一个未解释交互项 Delta_s。

### 3. 但 Delta_s 不能被神秘化

Delta_s 只是“现有基础状态解释不掉的残差”，不能被写成新的神秘能量。

后续它可能：
- 被更完善的气机本体吸收；
- 被证明是稳定的组合涌现项；
- 或只是某条传统经验规则，无法泛化。

这是必须保持的认识论边界。

### 4. “星系模态”与“宫位输出”必须继续分离

例如：
- 太阳巨门的“得助/孤立”是 L2 关系模态；
- 其在事业、夫妻、父母宫出现的具体事件，是 L3 场景投影；
- 最终吉凶属于 L4 评价。

若把“得助”直接写成“升职”，或者把“孤立”直接写成“离婚”，就重新退回固定星曜—事件映射。

### 5. G4 暴露出两个值得新增的 primitive 候选，但证据尚不足以正式冻结

#### QI-16-CAND：目标导向性
跨多个星系反复出现：
- 理想/幻想；
- 有目标/盲动；
- 果敢建设/无目的破坏；
- 上进/下游。

它与 QI-03 稳定—变动、QI-04 守成—开创、QI-08 行动驱动有关，但不完全相同。

#### QI-17-CAND：持续意志/韧性
跨多个星系出现：
- 意志坚强/薄弱；
- 坚忍/躁进；
- 刚毅/脆弱；
- 豁达/短志。

它可能与 QI-06 决策激活度、QI-08 行动驱动有独立信息。

红队建议：两者进入候选池，在 G5 状态空间构建时做冗余/可观性检查后再决定是否正式升格。

## 三、数据质量风险

### 1. OCR 标题存在少量误识别
例如第三组第 22 项，OCR 标题出现“太阳独坐卯酉”，但正文、宫位结构及六十星系分布歌均指向“太阴独坐卯酉”。

处理：
- 索引采用经正文结构校正后的“太阴独坐卯酉”；
- 保留 source-grounded-provisional 状态；
- 后续若制作论文附录，应人工核对原 PDF 版面。

### 2. 当前 principal mode 已覆盖60项，但“条件规则”尚未逐条穷尽原子化
G4 当前能冻结：
- 60 星系索引；
- principal mode；
- 交互建模架构。

不能声称已经把每个星系全部四化、辅煞、运限条件都完整结构化。

这些细则可在 WP-05/WP-06 或后续自动抽取中继续进入规则库。

## 四、模型结构风险

### 风险 A：Delta_s 与 z_s 双重计数
如果同时把 Delta_s 当作额外状态，又把 z_s 当作额外状态，可能重复表示同一交互。

建议正式规定：
- Delta_s 是“解释残差/交互函数”；
- z_s 是由完整星系状态派生出的模态标签或模态坐标；
- 两者不作为两个独立可加状态。

即：

~~~text
h_s = A_s(S) + Delta_s(...)
z_s = M_s(h_s, c)
~~~

### 风险 B：混杂系统表述过早数值化
目前可以说“形式上允许混杂/多模态动力学”，但还没有：
- 实际转移概率；
- 数值阈值；
- 模态切换数据。

因此 Paper 1 只能提出 hybrid-compatible formalization，不能声称已经识别出一个完整混杂控制系统。

### 风险 C：星系模式不一定都是二元
讲义常用“A/ B”来帮助辨别本质，但实际状态可能是：
- 连续轴；
- 多峰分布；
- 最适区；
- 条件簇。

因此 principal_mode 的 pole_a / pole_b 只是语义锚点，不应预设为二值分类器。

## 五、红队建议的 G4 冻结范围

建议冻结：

1. 六十星系完整索引与六组结构；
2. 每个星系至少一个 principal mode；
3. 星系统一模型：
   `base composition + interaction delta + mode + context gates`；
4. 星系模态属于中尺度，不自动成为 primitive qi；
5. Delta_s 是可约化的交互残差，不是新实体；
6. z_s 由完整星系状态派生，不与 Delta_s 重复计数；
7. 允许混杂/多模态表达，但暂不数值化模态转移；
8. QI-16 目标导向性、QI-17 持续意志/韧性只进入候选池。

暂不冻结：
- 每个 Delta_s 的具体函数；
- 每个 z_s 的连续/离散形式；
- 模态阈值；
- 每条四化、辅煞条件的完整参数；
- QI-16/QI-17 是否正式升格。
