## 三、第四组对模型的重要反馈

### 1. system mode 已明显不是单一吉凶轴

本组 principal modes 分别为：物欲/情欲、激发/遭忌、开创/因人成事、孤克/融合、奋发/刚戾、豁达/短志、适应/反拗、虚浮/沉稳、谦和/怯懦、理智/情绪。

这些模态同时覆盖驱动力、关系结构、承载能力、决策机制与环境适配，继续支持 z_s 为中尺度派生状态，而不是新增十组 primitive qi。

### 2. 非单调规则大量增加

第四组反复出现：化禄未必更好、化忌未必纯坏、强旺未必稳定、良运可能强化错误本质。例如：辰戌武曲化忌在一定条件下反激发进取；午太阳化忌在少煞时反可收敛为沉稳；下游天机遇良太阳也可能因安逸错失上进机会。

因此后续推演引擎必须允许 condition-dependent / non-monotonic operators，不能把禄权科忌映射成固定分数。

### 3. historical_context / path dependence 证据继续增长

天同、武曲、太阳、天府等章节都出现“某一大限形成的反应方式会影响后运”的描述。当前建议在未来扩展中引入 historical_context_t，但仍不修改G5的Paper-1主模型。

### 4. 人的反应不是噪声，而是文本内部的重要中介

源文多次区分：同样运限下，守成、冒进、退居幕后、选择合作、是否把握机会等反应会改变后续表现。这进一步支持未来把 u_t^human 与 u_t^astro 分开，并把 response policy 当成待因果检验的中介，而非把人的行为混入命盘输入。

### 5. 高风险应象必须继续停留在传统语义层

本组含疾病、婚姻、自毁、事故、诉讼等传统应象。已统一标记 traditional / historical semantic label，不转写为现代医学、心理学或法律因果结论。
