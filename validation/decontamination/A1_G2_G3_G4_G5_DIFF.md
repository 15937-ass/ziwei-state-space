# A1：G2 / G3 / G4 / G5 差异报告

## G2

### 保留
- L0 结构底座
- L1 内在状态
- L2 关系网络
- L3 场景投影
- L4 评价层
- 阴阳五行不强塞普通欧氏向量
- 状态变化与吉凶评价分离

### 修订
- ontology 从 200-rule pilot evidence 重拟合到全文 corpus
- QI-16 正式加入 L1
- QI-14 收窄并更换 evidence
- projection evidence 不再与 L1/L2 direct evidence 等权
- 原 QI-17 合并候选撤销

### 判断
**架构稳定，具体维度发生受控修订。**

## G3

### 保留
- L0 substrate
- intrinsic signature
- relational signature
- conditional/context layer
- 单星气核不是完整命理解释

### 修订
- 全部十四正曜执行 G3-R
- direct-star evidence 作为 intrinsic baseline 首要依据
- system-context evidence 不自动升格为单星 intrinsic
- 允许某颗星没有某一 QI
- outcome 不再反向充当等权 intrinsic evidence

### 判断
**结构保留，具体 star-core mapping 为本轮主要去污染对象。**

## G4

### 保留
~~~text
base composition
+ interaction_delta
+ principal mode
+ context gates
~~~

### 修订
- QI-16 从 candidate -> formal L1
- QI-17 原候选拆成 QI-17-CAND / QI-18-CAND
- resilience 改为 derived system property
- system-context evidence 与 single-star core 边界更严格

### 判断
**G4 架构未受实质挑战。**

## G5

### 保留
- fixed natal essence
- temporal exogenous input
- state-dependent reaction
- 12 palace local nodes + sparse graph
- astro/human/disturbance inputs 分离
- qi -> mode -> projection -> semantic output
- recursive dynamics 仍为未来 hypothesis

### 修订
- QI-16 进入状态接口
- QI-17/18 仍为候选
- path-count heuristic 不再称 structural observability
- 改名 ObservationPathSupport

### 判断
**动力学架构保留；控制理论术语收紧，避免过度声称。**

## 总结

A1 没有证明 G2-G5 “错了”。

更准确的结论是：

> 早期架构设计总体可靠，但具体本体映射与星曜气核在语料扩容后出现明显 anchoring、跨层和跨 subject 污染。

因此本轮采取：

~~~text
保留架构
+ 重拟合 evidence
+ 隔离 source mismatch
+ 降级过度理论化术语
+ 不删除 raw extraction
~~~

而不是重新从零开始。
