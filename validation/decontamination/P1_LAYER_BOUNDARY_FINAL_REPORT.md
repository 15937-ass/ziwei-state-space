## 1. Scope

P1 audited the 800 layer-boundary candidates selected from the 2,193-rule Zhongzhou sixty-system canonical corpus. The purpose was not to re-extract the chapter, but to test whether early normalizations had conflated:

- L1 intrinsic qi state;
- L2 relational state;
- system/mode compatibility;
- structural/context gates;
- derived response;
- L3 projection/outcome;
- sequence/lookahead semantics;
- source-explicit history memory.

Raw canonical extraction was preserved. Corrections and retypes were written as auditable sidecars.

## 4. Ontology consequences

P1 did **not** require a new primitive qi dimension, relational axis, or core operator family.

It reinforced the frozen G2/A1 separation:

`latent state != system compatibility != contextual gate != downstream event`

QI-14 received additional source support as information/state concealment-versus-disclosure. QI-16 remained a formal L1 state. QI-17/QI-18 remain separate candidates; P1 did not collapse them.

Existing QR-02 / QR-03 / QR-04 were sufficient for authority, conflict/pressure, and support-resource relational mechanisms encountered in the audited systems.

## 5. History consequences

A2-R1 typed memory remained sufficient:

- `ACQUIRED_DISPOSITION`
- `PATH_DEPENDENT_GATE`

After heuristic review, semantic backscan, and LB feedback, executable typed history transitions total **43**.

P1 explicitly rejected false history writes from:

- within-period sequence such as 先难后稳 / 先败后兴;
- lookahead instructions such as 先看以后数年再决定当前行止;
- flow-year vs decade input-scale differences;
- life-stage sustainability statements without an acquired state;
- generic statements about a favorable or unfavorable later period without source-explicit persistence/path dependence.

No continuous decay, memory weight, learning rate, or second independent memory timescale was introduced.

## 6. Model consequence

The six-system corpus now gives stronger support to a structured response model:

`response_t = R(E, z_system, u_t^astro, u_t^human, d_t, M_t, context_t)`

where:

- `E` remains fixed natal essence;
- `z_system` is a derived system mode, not a scalar goodness score;
- temporal inputs remain environment rather than automatically rewriting intrinsic nature;
- `M_t` changes only through source-explicit A2-R1 transitions;
- L3 events remain projections rather than latent-state coordinates.

This is still an internal formalization model, not an empirical proof of predictive validity.
