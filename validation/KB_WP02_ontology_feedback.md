# KB-WP02 本体反馈

## 结论

十四正曜全文 602 条规则没有迫使我们修改 G2–G5 冻结架构。

本轮最重要的反馈不是“增加更多维度”，而是加强以下建模原则：

1. **同一维度的 valence 强烈依赖场景。**
   武曲刚烈在事业/财帛与六亲宫评价不同。

2. **门控比简单加减更重要。**
   天同喜煞、天相夹宫、太阴昌曲/禄马等都必须先判断条件。

3. **机制来源应进入关系图。**
   辅曜“他力”与佐曜“自力”是支持资源来源机制，而非新的吉凶分数。

4. **输出标签必须与状态分离。**
   原书大量职业、六亲、健康、财富应象不应污染 L1/L2。

5. **星曜自身已经表现出模式切换。**
   廉贞阴柔/阳刚、天府空库/露库、贪狼物欲/情欲等，为 G4 的 mode 架构提供进一步源文支持。

## 暂缓新增

- 资源生成能力
- 成果留存
- 欲望类型
- 自力/他力

以上先作为派生变量、mode 或 operator metadata，等待六十星系全文再检查是否需要 primitive 升格。
