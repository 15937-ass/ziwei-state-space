## 一、总体结论

十四正曜可以在统一结构下表示为：

```text
L0：阴阳/五行结构标签
+
L1：内在气机气核
+
L2：关系网络气核
+
Conditional：会合、夹宫、四化、庙陷、运限等条件修正
```

这个结构比“每颗星直接对应若干事件”更稳定，也比“每颗星一个固定数值向量”更符合中州派原文。

## 二、红队认为已经成立的结构性发现

### 1. 星曜气核不能等于固定人格标签

天机在本命与运限中的意义不同；太阳存在过强/过弱的中和要求；武曲同一刚性在财官与六亲宫位评价不同；天相高度依赖夹宫和会合条件。

因此“星曜气核”只能保存基础倾向，不能直接写成：
- 某星=好/坏；
- 某星=某职业；
- 某星=某事件。

### 2. 条件修正层是必须的

至少以下星曜表现出强条件依赖：
- 紫微：孤君 vs 百官朝拱；
- 太阳：发射不足 vs 发射过度；
- 武曲：刚烈在不同宫位评价反转；
- 天府：正常财库 vs 空库/露库；
- 太阴：适度收敛 vs 过度收敛 vs 发射破坏；
- 巨门：多言/疑忌可被辅弼昌曲转化；
- 天相：夹宫可将软弱转为能力或进一步恶化；
- 天梁：同一太阳天梁可分祥和与孤忌；
- 破军：化禄改善变动过程，化权只增声势而不保证结果。

因此每颗星必须包含：
```text
base_core + conditional_modifiers
```
而不是只有 base_core。

### 3. 关系状态必须独立于内在状态

武曲孤克、天梁孤忌、紫微主导、七杀统帅、天相协同、辅佐资源等内容，若全部塞进个体内在向量，会丢失网络结构。

G2 的 L1/L2 分层在 G3 得到进一步支持。

## 三、逐星风险审查

### 紫微
风险：当前 ontology 中缺少“统摄/组织”这一更贴近紫微的潜变量，现有 QI-08 行动驱动只能部分承载。
建议：暂不新增正式维度，将“统摄/组织”列为 G4 候选扩展，等待六十星系检验。

### 天机
结构较完整。最大风险是把“聪敏”和“变化”混成同一维度。
建议：继续维持 QI-07 与 QI-03 分离。

### 太阳
结构很稳定。最重要的是不能把“发射高”直接等同于好。
建议：保持非单调中和模型。

### 武曲
结构稳定。注意“孤克”是关系层，“刚烈”是内在层。
建议：不合并。

### 天同
当前规则样本偏少，“缓冲/化解”较可靠，“享受”可能更接近欲望/场景表现。
建议：QI-09 对天同仅保留 secondary，不作为核心。

### 廉贞
“欲望驱动”与“感性—理性张力”均有支持。
风险：廉贞的“敏感/踏实”双态在六十星系章节更明显，单星阶段不宜过早加入新轴。
建议：G4 再处理。

### 天府
“资源保存/管理”与“守成”高度稳定。
风险：把“收敛”直接写成天府自身核心可能混入对武曲的调节作用。
建议：保留 QI-15 为 secondary，不升为 core。

### 太阴
“收敛/潜藏”核心清楚。
风险：QI-05 现实化—空泛与 QI-01 发射—收敛可能高度耦合。
建议：G4 做冗余检验。

### 贪狼
欲望驱动清楚。
风险：物欲、情欲、审美、活动性可能需要子结构，不应全部压成一个欲望强度。
建议：G4 检验“欲望类型向量”。

### 巨门
表达能力与遮蔽性可以同时存在，是很重要的双重结构。
风险：不能把“是非口舌”当作气核，而应是关系投影。
建议：当前处理正确。

### 天相
上下文敏感性极高。
风险：其“柔和”与“软弱”不是同义词。
建议：保留 QI-02 刚柔轴，但把软弱视为承载能力不足/条件结果，不等同于柔端。

### 天梁
原则/规范与孤忌均清晰。
风险：“调处纠纷”可能是 QI-10 原则性在关系场景中的投影，而不一定需要独立 QI-15。
建议：QI-15 仅 secondary。

### 七杀
刚克、独立、统帅、冲刺结构清晰。
风险：与破军共享“突破/冲刺”，但七杀更偏主帅决策，破军更偏先锋执行。
建议：G4 通过星系交互验证二者在 QI-04 / QR-02 上的不同组合。

### 破军
变动、冲锋、行动驱动清晰。
风险：不能把“破败/失败”写进气核；化权仅提高声势而不保证结果正好证明这一点。
建议：当前处理正确。

## 四、最关键的 G3 方法论结论

### 结论 A：星曜气核是“基态”，不是“完整解释”

形式上应写成：

```text
S_i^0 = base latent core
S_i(context) = T_context(S_i^0)
```

其中 `T_context` 包括：
- 同度/会合；
- 辅佐煞化；
- 宫位；
- 庙旺落陷；
- 本命/运限；
- 后续星系交互。

### 结论 B：G4 必须把六十星系视为交互模型

至少已有证据表明：

```text
Phi(S_i, S_j) != S_i + S_j
```

例如：
- 武曲 + 破军：刚烈进一步转成躁决；
- 天相在不同夹宫结构下发生性质转化；
- 太阳天梁可分“祥和”和“孤忌”两类本质；
- 紫微破军对四化异常敏感。

因此 G4 的重点不是“把两个星的标签相加”，而是识别 `interaction_delta`。

## 五、红队建议的 G3 冻结范围

建议冻结：
1. 十四正曜统一使用“结构底座 + 内在气核 + 关系气核 + 条件修正”的数据结构；
2. 每颗星的 core/secondary/conditional 分级原则；
3. 事件结果不得进入星曜 primitive core；
4. 关系性质不得混入纯内在状态；
5. base core 与运限表现必须分层；
6. G4 明确使用非线性交互项。

不建议冻结：
1. 每颗星所有维度是否已经穷尽；
2. qualitative strength 是否未来对应多少数值；
3. 统摄/组织、欲望类型、敏感/踏实等候选新维度；
4. context_sensitivity 等级本身的数值意义。

## 六、是否可以进入 G4

**可以。**

当前十四正曜气核结构已经足够作为六十星系建模的输入，但必须保持“可修订”状态，待 G4 的交互分析反向修正单星气核。
