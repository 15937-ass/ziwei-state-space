## 二、最重要的模型修正

### G5-1：不把中州派原文强行写成“逐年递推系统”

此前我们曾经考虑：

~~~text
x_(t+1)=F(x_t,u_t)
~~~

但下册宫垣论真正直接支持的是：

> 先确定原局十二宫的“本质”，再把大限、流年移动后的星曜结构视为对原有本质的“反应”。

所以现在正式建议把 Paper 1 的源文核心写成：

~~~text
u_(p,t) = 当期外生时序输入

r_(p,t) = R(
    e_p,
    u_(p,t),
    z_(p,t),
    G_t,
    c_t
)

y_(p,t) = P_p(r_(p,t), c_t)
~~~

其中：

- e_p：第 p 宫固定的原局本质；
- u_(p,t)：大限/流年等当期输入；
- z_(p,t)：星系模态；
- G_t：关系结构；
- c_t：现实上下文；
- r_(p,t)：当期反应；
- y_(p,t)：现实语义输出。

核心性质：

~~~text
R(e_a,u) != R(e_b,u)
~~~

也就是：

> 同一个运限结构作用在不同原局本质上，会产生不同反应。

这比直接套经典 LTI 模型更忠实于中州派。

## 三、真正的递归状态空间模型放在哪里

真正的现代动力系统：

~~~text
x_(t+1)=F(x_t,E,u_t,z_t,G_t,c_t)+w_t
y_t=H(x_t,E,z_t,c_t)+v_t
~~~

仍然保留，但明确标记为：

> **未来需要纵向命例数据验证的 HYPOTHESIS。**

也就是说第一篇不会写成：

> “中州派本来就是一个状态空间系统。”

而应该写成：

> “中州派的本质—反应结构可以嵌入一个潜状态动力系统框架；递归动态部分是为后续系统辨识提出的扩展模型。”

这能避免过度包装。

## 五、辅佐煞化正式放在哪一层

建议冻结为：

~~~text
T_m(state, mode, context)
~~~

允许五种作用：

1. 加强；
2. 削弱；
3. 转化；
4. 门控；
5. 耦合。

其中四化必须写成：

~~~text
T_(star,hua)
~~~

而不是一个统一：

~~~text
T_hua
~~~

因为：

- 太阴化权；
- 贪狼化权；
- 天府化科；
- 贪狼化忌；

作用的目标和表现明显不同。

同时：

> 辅曜偏“他力”，佐曜偏“自力”。

因此也不能全部并成一个“吉曜增益”。

## 七、结构可观性怎么处理

现在没有数值 A、C 矩阵，所以不应该计算经典：

~~~text
rank(O)
~~~

并宣称“系统可观”。

第一篇只冻结一个**结构可观性审计标准**。

一个候选气机维度至少需要满足：

### 1. 输出可达
存在：

~~~text
q -> ... -> observable output
~~~

### 2. 与其他维度可区分
两个维度不能拥有完全相同的：
- 星曜支持；
- 星系支持；
- 修正曜作用；
- 宫位投影；
- 输出路径。

### 3. 最好存在差异激励
至少有某些星曜/修正条件可以分别作用于两个相近维度。

### 4. 跨上下文含义稳定
不能只是某一句古文里的孤立词语。

### QI-16：目标导向性

~~~text

  QI-08 行动驱动,
~~~

所以先做派生状态。

### QI-17：持续意志/韧性

**建议暂不升格，但保留为高优先级候选。**

理由：

它与：

- 行动驱动；
- 决策速度；

不完全一样。

一个人可能：
- 很容易行动，但很快放弃；
- 决断很快，但抗挫性很低。

不过现有规则还不足以证明它拥有完全独立的 operator/output path。
