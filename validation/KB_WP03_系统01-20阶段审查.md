## 三、本轮新增的重要模型证据

### 1. 星系 principal mode 不是简单二元标签

例如：
- 同梁：浪漫 / 原则纪律，可调和，也可冲突；
- 武杀：决断 / 短虑，外表均可果断，差异在决策质量与是否留有余地；
- 辰戌太阳：受拖累 / 不受拖累，是关系负荷模态；
- 子午天机：阳刚为公 / 阴柔谋私，与福德宫同梁、太阴、巨门共同决定。

因此 `z_s` 继续保持为连续/序数/离散均可的中尺度模态，不强制二值分类。

### 2. 路径依赖在中州派源文中开始明显出现

同梁章节明确描述：
- 关键太阳/巨门大限是否开运，会影响后续廉贪运限的层级。

这并不足以直接证明递归 `x_(t+1)=F(x_t,...)`，但说明未来需要区分：
- 固定 natal essence；
- 历史运限形成的 path-dependent context。

按 G5 冻结原则，本轮只记录为未来动力学候选，不修改 Paper-1 主模型。

### 3. 同一输入对不同 system mode 产生不同反应

系统17–20反复出现：
- 同一刑忌作用于原则型/浪漫型同梁，外部纠纷与内部焦虑不同；
- 天机化忌作用于决断型/短虑型武杀，损失机制不同；
- 同一星系运限作用于受拖累/不受拖累太阳，增益幅度不同；
- 相同动荡宫限作用于阳刚/阴柔天机，可能分别开创新局或因人际变化生咎。

这进一步支持：

~~~text
R(e_a,u,z_a) != R(e_b,u,z_b)
~~~

而不是固定 rule -> event。
