# src

Executable implementation will begin only after Rule Schema v0.1 and the initial candidate ontology are reviewed.

Planned modules:

- `schemas/` — typed rule and ontology models
- `knowledge/` — loaders and validators
- `model/` — star, star-system, modifier, palace representations
- `dynamics/` — state transition functions
- `analysis/` — structural observability, sensitivity, consistency checks
- `provenance/` — source traceability

Rule: implementation must not silently add domain knowledge absent from approved artifacts.
