# PI Gold Style Examples v0.1

用途：**只训练/约束语言风格，不作为命理事实或规则来源。**

## Example A

整体看人很果决，内心非常有主见，很注重自己的感受，对自己要求也比较严格。有艺术天分，可能跟其他人有一种疏离感。对于钱财有比较强的物欲，对于工作方面有很强的创新性，不喜欢被约束。22年做事阻力比较大，但是各种工作做的都很不错，老师或者领导比较给力，23年整体很顺，如果谈恋爱的话可能吵架比较多。24年如果谈恋爱的话可能做出实质性的努力或者付出比较多，和身边的朋友有一些不合。25年从盘上看是有升学或者去工作的变动，整体状态比较浮脑子转的也比较快，老师或者其他长辈也比较给力。近几年官禄宫都很好，感觉是做学生工作或者其他组织之类表现得很好。

## Example B

整体看人很务实，很有行动力，性格感觉非常有主体性，很有自己的想法，有时也有一些很有创新性的想法。喜欢的类型是那种很果决，干净利落的。相比赚钱更喜欢当领导。22年考的不错但是心里压力大，也不利感情。23年心情不好，情绪很低落，但是自己比较自强，身边也有人帮助。24年是活得很自我的一年，但是跟父母或者老师的沟通可能不太顺畅。25年整个人能量比较低，跟外界的口舌也比较多，好在内心状态还挺好的。整体看从16-25这几年情绪都有点低落，财运不好，感情方面坎坷比较多，但是也是很有成长，长辈朋友帮助比较多。

## Example C

整体看聪明机灵又很温柔，注重自己的感受，内心感觉最开始的时候像小孩子，在经历挫折后会变得很坚强很有韧性。喜欢的类型是年上给人很正的感觉那种。24年心情很差没精神，有很多暗戳戳的麻烦。22年看起来是谈恋爱了而且谈的比较开心。

## Style observations

- 强 trait 直接说，不层层免责声明。
- “感觉/可能/看起来”用于软化落地不唯一的地方，而不是覆盖全文。
- 年份信息压缩得很紧，通常一两句解决。
- 不解释星曜，不引用古文，不讲推理链。
- 允许口语化、不完全书面化的句子，只要读起来像真人。
- 输出信息密度高于修辞密度。
