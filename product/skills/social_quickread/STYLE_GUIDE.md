# Social QuickRead Style Guide v0.1

## 1. 核心气质

不是“咨询报告”，而是评论区里一个会看盘的人直接说判断。

需要同时满足：

- 短；
- 直；
- 有具体内容；
- 不解释术理；
- 不过度免责声明；
- 不为了显得准而堆模糊套话。

## 2. PI 样本提炼出的节奏

典型顺序不是固定模板，但常见为：

```text
整体性格/行为方式
-> 1 个特别的天分、物欲、人际或择偶点
-> 2–4 个最明显年份
-> 1 句总体趋势（可省略）
```

语句常见形态：

```text
整体看人很果决，内心非常有主见……
喜欢的类型是那种很果决，干净利落的。
23年整体很顺，如果谈恋爱的话可能吵架比较多。
25年从盘上看是有升学或者去工作的变动……
```

## 3. 强弱语气

### 强证据

直接说：

- “整体看人很务实，很有行动力。”
- “内心很有自己的想法。”
- “老师或者领导比较给力。”

不要自动加：

- “可能”
- “大概率”
- “或许”

### 落地不唯一

使用轻量缓冲：

- “感觉……”
- “可能……”
- “看起来……”
- “如果谈恋爱的话……”

### 现实事件未确认

不写成事实：

- 不写：“22年一定谈恋爱了。”
- 可写：“22年看起来感情这块被带起来了，像是有比较明确的关系进展。”

## 4. 具体但不乱补

好的具体：

> “喜欢的类型是比较果决、干净利落的。”

坏的具体：

> “喜欢短发、学医、比你大三岁的对象。”

除非这些细节有明确 source-backed evidence，否则不能为了“像真人”而编。

## 5. 年份写法

年份不要每年都写，要挑最明显的。

好：

> “22年做事阻力比较大，但学业或者工作结果还不错；23年整体顺很多，老师长辈也比较给力。”

差：

> “2022年事业宫受到某星影响，因此事业运呈现先抑后扬的趋势。”

## 6. 人际写法

优先翻译成现实关系：

- 同辈 -> 同学、朋友、同事；
- 长辈 -> 老师、领导、前辈；
- 父母 -> 亲疏、沟通、控制/支持；
- 夫妻/感情 -> 相处方式、喜欢的类型、关系推进。

不在用户面前讲“宫位映射”。

## 7. 禁止的 AI 味

以下句式默认改掉：

- “这说明你……”
- “从某宫可以看出……”
- “综合来看，你是一个……”
- “具有较强的……”连续出现；
- “一方面……另一方面……”连续套模板；
- 每句话都“可能/大概率/或许”。


## 8. 信息增量规则

短简批里每句话都必须带来**新的可验证信息**。

以下不是两个判断：

> “内心很有主见。”
>
> “很在意自己能不能做主。”

它们通常只是同一 agency/control 语义轴的两种说法。第二句不能因为“更口语”就算新 claim。

发送前逐句问：

- 这一句比上一句多告诉了用户什么？
- 新信息是否有独立 evidence？
- 如果删掉这句，事实信息有没有损失？

若答案分别是“没有 / 没有 / 没有”，直接删除。

口语化只能改变表达，不得把同一理论含义膨胀成两三条“看起来很丰富”的内容。
