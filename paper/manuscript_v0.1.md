# Manuscript v0.1

## 题目

**中州派紫微斗数的理论约束潜状态形式化：从星曜、六十星系到原局—运限反应**

English working title:

**A Theory-Constrained Latent-State Formalization of Zhongzhou Zi Wei Dou Shu: From Stellar Systems to Natal–Temporal Responses**

---

## 摘要

紫微斗数主要以星曜、星系、宫垣、辅佐煞化与运限规则构成，其知识长期以自然语言、口诀和经验性“征验”形式保存。本文不预设紫微斗数对现实人生具有经验预测效度，而将研究目标限定为：检验中州派知识体系能否被转换为一个可追溯、可计算、可审计的形式系统。

本文以王亭之中州派讲义为主要语料，首先建立原子规则模式，将源文陈述与研究者归一化解释、状态变化方向与吉凶评价严格分离。随后将传统“气”操作性定义为潜状态表示，构造 L0–L4 分层本体：阴阳五行等结构底座、内在气机状态、关系网络状态、十二宫场景投影与评价层。十四正曜被表示为“结构底座 + 基础气核 + 关系气核 + 条件修正”；六十基本星系被表示为单星可解释成分、交互残差、星系模态与上下文门控的中尺度状态。辅佐煞化被形式化为加强、削弱、转化、门控和耦合算子；十二宫则被表示为相互耦合的场景投影节点。

依据中州派“先认识原局宫垣本质，再考察大限流年对其反应”的方法，本文提出 Paper-1 核心反应模型：固定原局本质 E、外生时序输入 U_t、星系模态 Z_t 与宫位关系图 G_t 共同产生时点反应 R_t，再经宫位/现实上下文投影为输出 Y_t。真正的递归状态方程仅作为后续系统辨识假设，而非传统文本已经给出的动力学定律。

当前机器可读试验语料包含 200 条原子规则，覆盖十四正曜；六十基本星系已建立完整索引。20 条双遍审核样本中，来源追溯与认识论标签通过率为 100%，原子化直接通过率为 90%。结构能观性审计未发现当前核心候选中完全缺乏输出路径的变量，但若干维度仅具有部分结构可观性。三个教材内部重构案例显示，当前模型能够表示“同一运限作用于不同原局本质产生不同反应”“原局宫位本质与后天刺激分层”以及“跨宫联合投影”等中州派核心推理依赖。

上述结果只表明中州派知识能够在当前范围内被较一致地形式化，不构成对紫微斗数现实预测力、因果有效性或物理机制的验证。本文为后续更完整的规则抽取、结构可辨识性研究、命例数据库建设与受约束系统辨识提供形式基础。

**关键词：** 紫微斗数；中州派；潜状态；知识形式化；灰箱建模；混杂系统；结构能观性

# 1. 引言

## 1.1 问题背景

中州派讲义自身将紫微斗数区分为星曜与宫垣两大部分，并提出先研究星曜及其三方四正组合形成星系，再根据星系性质研究宫垣之间的干涉。十四正曜构成基础，六十基本星系构成发展，辅佐煞化等则对原星系性质产生加强、削弱或转化。

这类知识具有明显的结构性，但仍以自然语言形式保存，导致几个方法问题：

1. 同一概念可能有多种措辞；
2. “性质”“吉凶”“事件”经常位于不同逻辑层却容易被混写；
3. 单星、星系、宫位与运限之间的依赖关系难以直接进入计算模型；
4. 若直接以“某星=某事件”编码，容易形成不可证伪的事后解释；
5. 若过早人为赋数值，又会把研究者主观偏好伪装成参数。

中州派序论同时明确把斗数视为仍需统计、征验和理论整理的术数，并指出现代社会背景会要求对旧有经验进行修改或补充。本文据此不把传统规则视为已经验证的科学规律，而把它们视为待形式化和待检验的理论先验。

## 1.2 研究目标

本文的目标不是回答“紫微斗数是否真实有效”，而是回答：

> 一个以中州派为边界的传统规则系统，能否被转换为具有明确状态、关系、算子、输入、输出和证据链的可执行模型？

具体研究问题为：

- RQ1：星曜—星系—宫垣—运限能否被表示为层级状态模型？
- RQ2：中州派“本质—反应”能否被形式化为状态依赖反应？
- RQ3：能否用符号参数和约束保存传统知识，而不提前制造连续权重？
- RQ4：该形式系统能否通过规则完整性、审计、结构能观性与教材内部重构等方式进行内部验证？

## 1.3 贡献

本文的贡献限定为四项：

1. 建立源文可追溯的原子规则 schema；
2. 建立 L0–L4 分层潜状态本体及十四正曜气核；
3. 将六十星系形式化为具有交互残差与模态的中尺度系统；
4. 建立“固定原局本质 + 时序外生输入 + 状态依赖反应 + 宫位投影”的 Paper-1 核心模型，并提供结构能观性审计与可执行软件规格。

# 3. 原子规则形式化

## 3.1 Rule Schema

每条规则表达：

~~~text
Subject + Context + Condition -> Effect on Target
~~~

关键字段包括：

- 来源与位置；
- 主体、条件、时间范围、宫位范围；
- 原文近似目标与归一化目标；
- 算子；
- state_change；
- valence；
- 认识论标签；
- 证据文本；
- 审核状态。

## 3.2 状态变化与评价分离

例如“刚烈增加”不等于“更好”，因为同一性质在不同宫位或不同星系中可能有相反评价。

因此：

~~~text
state_change = increase
valence = context_dependent
~~~

而不是：

~~~text
positive = true
~~~

## 3.3 当前语料

当前结构化样本共 200 条：

- 紫微、天机、太阳、武曲各 25 条；
- 其余十正曜各 10 条。

所有关键 schema 字段当前均非空，但这只代表机器结构完整，不代表全文覆盖完毕。

# 4. 分层气机本体

## 4.1 操作性定义

本文把“气”操作性定义为：

> 用于统一表征中州派文本中重复出现的方向性、关系性和动力学性质的潜状态变量。

不把它定义为已被现代实验确认的物理能量。

## 4.2 L0–L4

~~~text
L0：结构底座
    阴阳、五行、图结构

L1：内在气机
    发射—收敛、刚—柔、稳定—变动等

L2：关系网络
    孤离、支持、主导、竞争等

L3：场景投影
    十二宫所对应的现实语义域

L4：评价层
    吉凶、风险、适配、中和
~~~

这使“状态”“关系”“输出”“评价”不再共用一套标签。

# 5. 十四正曜气核

第 i 颗星的基础气核记为：

~~~text
S_i^0
~~~

在上下文 c 下：

~~~text
S_i(c)=T_c(S_i^0)
~~~

每颗星统一包含：

- L0 阴阳/五行标签；
- L1 内在气机；
- L2 关系气机；
- contextual sensitivity；
- conditional modifiers。

星曜气核不是完整命理结论，更不是固定事件映射。

例如太阳的“发射”存在过强与不足两类失衡，因此发射强度不是单调吉凶变量；武曲的刚性在不同宫位可呈现不同评价。这些现象要求状态层与评价层分离。

# 6. 六十星系：交互与模态

## 6.1 统一形式

第 s 个星系：

~~~text
H_s = Phi_s(S_1,...,S_n,R_s,c)
~~~

为分析组合性质，引入：

~~~text
h_s = A_s(S) + Delta_s(S,R_s,c)
z_s = M_s(h_s,c)
~~~

其中：

- A_s：当前单星气核可解释部分；
- Delta_s：尚未被基础本体解释的交互残差；
- z_s：星系模态。

Delta_s 不代表新的实体，只代表当前模型解释不掉的组合部分。

## 6.2 Principal Mode

当前 60 个基本星系全部建立索引，并保留一个 source-near principal mode。

星系模态被归为约 10 个可复用族，包括：

- 平衡/中和；
- 稳定/变动/适应；
- 目标/进取；
- 欲望/情感；
- 原则/权威；
- 认知/现实化；
- 意志/韧性；
- 关系支持；
- 资源统筹；
- 条件门控状态。

这使 60 个星系可以共享交互机制，而不是成为 60 个互不相关的黑箱。

# 7. 辅佐煞化算子

统一定义：

~~~text
x' = T_m(x,z,c)
~~~

允许：

- enhance；
- weaken；
- transform；
- gate；
- couple。

四化使用：

~~~text
T_(star,hua)
~~~

而不是统一 T_hua，因为同一个“化”作用于不同星曜时目标与副作用不同。

多个修正曜并存时，不采用简单“吉星正分 + 煞星负分”抵消模型。

# 8. 十二宫投影与原局—运限反应

## 8.1 原局本质

对宫位 p：

~~~text
e_p = E_p(H_p^natal,G_0)
~~~

全局：

~~~text
E={e_1,...,e_12}
~~~

十二宫既是局部节点，也通过三方四正及源文明示的跨宫依赖形成稀疏图。

## 8.2 时序输入与反应

~~~text
u_(p,t)=U_p(chart_t,transformations_t,modifiers_t,G_t)

r_(p,t)=R_theta(
    e_p,
    u_(p,t),
    z_(p,t),
    neighborhood(E,G_0),
    c_t
)
~~~

关键条件：

~~~text
R(e_a,u) != R(e_b,u)
~~~

即相同运限结构可因原局本质不同产生不同反应。

## 8.3 场景投影

~~~text
y_(p,t)=P_p(r_(p,t),c_t)
~~~

最终链条：

~~~text
symbolic structure
-> latent state
-> star-system mode
-> palace reaction
-> contextual projection
-> semantic outcome
-> observable event
~~~

不允许直接：

~~~text
star -> event
~~~

# 9. 控制理论接口与边界

## 9.1 外生输入

大限、流年、当期四化等记为：

~~~text
u_t^astro
~~~

它们不是人的控制输入。

## 9.2 人类行为

未来可能定义：

~~~text
u_t^human
~~~

但只有在具有因果/干预数据后，才讨论 controllability 或 optimal control。

## 9.3 递归动力学

未来可检验：

~~~text
x_(t+1)=F_theta(
    x_t,E,u_t^astro,u_t^human,d_t,z_t,G_t,c_t
)+w_t
~~~

但这属于 HYPOTHESIS，不是本文从中州派文本直接抽出的定律。

## 9.4 Hybrid-compatible

由于同时存在连续/序数状态和星系模态 z，本文模型与 hybrid/switched dynamical representation 兼容。

本文不声称已经识别出一个数值混杂控制系统。

# 10. 内部验证

## 10.1 规则审计

200 条规则关键字段完整率为 100%。

20 条双遍审查样本：

- provenance：20/20；
- epistemic type：20/20；
- target mapping：20/20；
- atomicity：18/20。

因此 schema 在试验范围内具有较高可执行性，但尚无独立人工双标可靠性指标。

## 10.2 结构能观性

当前只做结构通路与可区分性分析。

没有发现正式核心变量完全缺乏输出通路。

部分可观变量包括：
- 决策激活度；
- 感性—理性张力；
- 遮蔽—显明；
- 竞争激活；
- 支持资源。

这不等于经典控制意义上的完全能观。

## 10.3 教材内部重构

Case 1：同一或近似运限结构作用于不同原局本质，产生不同反应。  
Case 2：原局子女宫本质与后运刺激分层。  
Case 3：事业/财帛等主题需要跨宫联合投影。

三类推断依赖均可以由当前模型明确表达。

# 11. 讨论

## 11.1 模型的意义

本文将一个传统规则系统转换为：

- 可追溯规则；
- 分层状态；
- 非线性交互；
- 图结构；
- 时序反应接口；
- 可执行软件对象。

这使未来研究可以明确问：

- 某个传统概念是否冗余？
- 某个潜状态是否可观？
- 某种星系交互是否需要独立项？
- 某个参数是否可由数据辨识？
- 加入某个流派模块是否提高外部预测力？

而不是只能以整体“准/不准”争论。

## 11.2 理论约束灰箱视角

当前模型最接近理论约束的灰箱结构：

- 结构由传统文本提供；
- 连续参数未知；
- 未来由数据估计；
- 不允许数据模型任意破坏已冻结的结构约束，除非通过版本化模型比较证明旧结构需要修改。

## 11.3 最大风险：不可证伪的应象解释

如果任意现实事件都能在事后找到某个“象”，模型将永远不会失败。

因此未来外部验证必须预先定义：

- 事件分类；
- 时间窗；
- 输出概率；
- 成功/失败标准；
- 对照基线。

未命中的预测必须计为失败，而不能事后重新解释。

# 12. 局限性

1. 当前 200 条规则不是完整语料库。
2. OCR 仍可能造成原文错误。
3. 当前双遍审核并非真正独立人工标注。
4. 潜状态本体仍可能存在隐藏冗余。
5. 没有真实纵向命例数据库。
6. 没有参数估计、外部预测检验或前瞻性验证。
7. 没有因果干预数据。
8. 阴阳五行当前仅作为结构底座，尚无数值嵌入。
9. 递归动力学、observer 和 controllability 均未验证。

---

# 13. 结论

本文提出了一套用于形式化中州派紫微斗数的理论约束潜状态框架。在当前语料范围内，十四正曜、六十星系、辅佐煞化、十二宫以及原局—运限反应可以被表示为具有明确层级、交互算子、上下文依赖和证据链的机器可读系统。内部规则审计、结构能观性分析与教材逻辑重构说明，该框架在形式层面具有可执行性和可审计性。

这些结果**不构成紫微斗数经验预测有效性的证据**，也不说明“气”具有已被实验确认的物理实体地位。本文的贡献是把一个传统自然语言规则系统转化为可以进一步被统计、系统辨识、消融和前瞻性实验检验的研究对象。

下一阶段将建设更完整的规则与纵向命例数据库，并检验：在预注册事件定义、严格 person-level 数据划分和适当基线下，传统结构约束是否提供超出人口学、历史状态和随机模型的增量预测信息。
